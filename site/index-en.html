03 / Common questions

Find an answer.

Do I need a cloud platform?

No. After Wi-Fi setup, the local web interface works directly. MQTT and Home Assistant can also run entirely on your LAN.

Does a Wi-Fi update enable every M1 controller feature?

No. The Wi-Fi module and sensor controller update separately. Extended features require matching versions and capabilities. Stock 17.x migration is currently discouraged.

Can I download the DAIKIN hub or use Apple Home now?

DAIKIN hub is available as a Beta (RC) build and is not recommended for use. Apple Home uses experimental HAP bridging, pending physical-device validation. This version does not include Matter.

What if Wi-Fi setup, MQTT or an update fails?

Check your model and version, then follow troubleshooting and the matching installation guide. Include reproduction steps when reporting an issue, and remove passwords and tokens.
