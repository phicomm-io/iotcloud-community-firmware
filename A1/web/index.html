空气净化器

0 为关闭。显示设置百分比；风机逐步调整输出，设备没有转速回读。

长按面板 Wi-Fi 键 2.5 秒可开启配网热点，童锁期间仍可使用。

灯环

未启用常亮时，控制后显示两秒。风机开启时显示风速条，关闭时显示整圈；Wi-Fi 指示位置单独显示连接状态。

Wi-Fi 配网

保存后若热点断开，请切回家庭 Wi-Fi，在路由器中查找设备 IP。连接失败会重新开启配网热点。

MQTT / Home Assistant

legacy 需在平台手动绑定；account 上线后自动加入云端列表。切换账户或模式会尝试清理旧 HA 实体。失败时需在旧 Broker 手动清理。

HA 配置 MQTT 集成后，设备会自动创建空气净化器控制、RGB 灯环、童锁和常亮开关。

设备设置

网页管理密码

密码留空将关闭网页认证；启用后浏览器会要求重新登录。

固件升级

选择本项目的 A1 OTA 包。校验成功后设备自动重启，保留 Wi-Fi、MQTT 、风机和灯环配置。

设备诊断


绑定与联动
先在任一端添加对方 MAC，两台设备使用同一个 MQTT Broker。握手成功后才启用联动。可填写局域网 IP；留空时通过 MQTT 地址公告查找。关闭恢复检查后，可手动探测；强制 MQTT 会停用局域网传输。
