让 A1 连接 Wi-Fi

无需原厂 App。电脑先无线连接目标 2.4 GHz Wi-Fi，再填写同一个网络的信息。

  1. 电脑使用 Wi-Fi 连接，不能用网线代替。
  2. 开始发送后，让 A1 进入配网模式；接收窗口约 60 秒。
  3. 发送结束后，在路由器客户端列表确认 A1 获得 IP。

Windows 用 ipconfig 查看 WLAN 的 IPv4；请勿填写路由器、VPN 或有线网卡地址。

如何让 A1 进入配网模式？

原厂代码在特定触摸输入持续约 1 秒后启动配网。触摸寄存器与面板具体图标尚未核对，因此这里不能指定某个按键。首次使用需先确认设备已进入配网状态；未配置开机也不能仅凭日志认定自动进入。
