让 A1 连接 Wi-Fi

无需原厂 App。电脑先无线连接目标 2.4 GHz Wi-Fi，再填写同一个网络的信息。

  1. 电脑使用 Wi-Fi 连接，不能用网线代替。
  2. 开始发送后，单独按住 A1 面板的 Wi-Fi 图标键 1–2 秒后松开；接收窗口约 60 秒。
  3. 发送结束后，在路由器客户端列表确认 A1 获得 IP。

Windows 用 ipconfig 查看 WLAN 的 IPv4；请勿填写路由器、VPN 或有线网卡地址。

如何让 A1 进入配网模式？

单独按住面板的 Wi-Fi 图标键 1–2 秒后松开，接收窗口约 60 秒，无需连接设备热点。已经保存过 Wi-Fi 也能重新配网。本工具按原厂固件逆向实现，A1 理论上可用。
