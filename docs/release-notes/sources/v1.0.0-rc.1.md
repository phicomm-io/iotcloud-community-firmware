v1.0.0 的第二个候选版本，延续已发布 v1.0.0-rc 的功能；本节列出本次大金中枢与网页入口的增量。HomeKit 对本机传感器的支持沿用已发布 RC。

### 大金中枢管理列表

- 中枢自动出现在自己的设备列表，可直接查看本机传感器并进入设备设置。本机项不占用 12 个外部设备名额，也不能被当作外部设备删除或重复注册。

### 本地管理与版本转换

- 首次设置中枢及打开本地管理时，不再强制预先设置设备网页密码；已有网页密码时仍需正确鉴权。中枢本地账户的登录密码仍独立保留。
- 声明转换能力的新版 full，可在局域网网页选择匹配的 hub 签名包并明确确认切换，不再要求先设置网页密码；已有密码时仍需鉴权。机型、签名与实际 OTA 容量检查继续有效，转换保留联网配置；普通 OTA 继续隔离变体，不支持直接 hub → full OTA。

### HomeKit 状态显示

- 调整 HomeKit 开关或重置配对后，网页会在等待重启期间继续检查状态；服务恢复后显示当前状态，会话失效时提示重新登录。等待期间不重复提交开关或重置请求，也不显示过期配对码。
