v1.0.0 的第二个候选版本，延续已发布 v1.0.0-rc 的功能；本节列出通用数值来源、大金中枢与网页入口的增量。HomeKit 对本机传感器的支持沿用已发布 RC。

### 大金中枢管理列表

- 中枢自动出现在自己的设备列表，可直接查看本机传感器并进入设备设置。本机项不占用 12 个外部设备名额，也不能被当作外部设备删除或重复注册。

### 本地管理与版本转换

- 首次设置中枢及打开本地管理时，不再强制预先设置设备网页密码；已有网页密码时仍需正确鉴权。中枢本地账户的登录密码仍独立保留。
- 声明转换能力的新版 full，可在局域网网页选择匹配的 hub 签名包并明确确认切换，不再要求先设置网页密码；已有密码时仍需鉴权。机型、签名与实际 OTA 容量检查继续有效，转换保留联网配置；普通 OTA 继续隔离变体，不支持直接 hub → full OTA。

### HomeKit 状态显示

- 调整 HomeKit 开关或重置配对后，网页会在等待重启期间继续检查状态；服务恢复后显示当前状态，会话失效时提示重新登录。等待期间不重复提交开关或重置请求，也不显示过期配对码。

### 通用数值来源

- 设备以传感器数据 schema 2 发布任意字段 ID 及其名称、类型、单位、数值、有效标志和读数年龄（`name/type/unit/value/valid/age_ms`）。TC1 功率、A1 主风机生效输出、大金和 M1 的传感器读数均声明为 `number`；A1 输出为 0–100%，不是 RPM。无效数值使用 `null`，不以 0 代替。
- M1 显示配置 schema 4 按“设备 + 字段”选择来源，不再按设备型号适配。来源设备增加数值字段后，无需新增型号映射；M1 仅接受类型和单位匹配的 `number`。缺失、无效或 `unknown` 等非数值字段不再沿用旧读数；协议保留未来类型扩展。

读数沿用启动标识 `boot`、序号 `sequence` 和 `age_ms` 判断新鲜度，区分重启前后数据、重复消息及过期读数。

本版传感器数据采用 schema 2、M1 显示配置采用 schema 4，不兼容 v1.0.0-rc 的对应旧接口；自定义调用方需按 RC1 协议调整，并使用配套前端。
