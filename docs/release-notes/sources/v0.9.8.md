- A1 自动与手动模式独立于电源，自动模式按空气质量调速，支持风速上下限、离线风速及独立夜间范围；手动关机后不会被空气质量联动打开。
- 新增可选启停回差：达到启动阈值后运行，降到目标值后待机，区间内保持原状态；支持 PM2.5、甲醛和组合指标，条件持续时间及最短运行／待机时间共同抑制频繁启停。运行期间按固定、线性或 PID 算法调速。
- 本地网页和集中管理平台均可切换模式、调整自动上限、设置目标与启动阈值；平台列表显示自动／手动及运行／待机／关机状态。
- 电源键默认双击切换自动／手动，模式设置以青色双脉冲／暖橙色单脉冲确认；Home Assistant 模式与 HomeKit Bridge 同步，保留电源状态与手动风速记忆。
- 保留 Wi-Fi、MQTT、绑定、滤芯、按键与定时配置；启停回差默认关闭，升级后可按需启用。
