- 优化 A1、M1、TC1 网页状态刷新：首次打开读取完整状态，日常刷新按需读取实时数据，网络与诊断信息按页面加载或降低刷新频率，减少设备负担与传输量。
- 统一 A1、M1、TC1 的 HTTP 服务后端，共用连接管理、请求解析和异常处理逻辑，减少重复代码与机型间的行为差异。
- HTTP 与 MQTT 复用设备现有的权威状态结构体，通过统一的状态快照接口和 JSON 编码器生成数据，减少重复采集与编码逻辑。采集仅短时间持锁，编码和网络发送不持有状态锁，减少各环节之间的相互牵制。
- 统一 MQTT 的连接、重连、命令队列与发送调度，改善网页与 MQTT 同时访问时的响应和资源管理，优先处理命令确认；高负载时允许返回繁忙，负载下降后恢复服务。
- 修复 TC1 异常 HTTP 连接处理与资源回收问题，减少功率、电量读取及数字转换的内存开销，降低长时间运行时卡死、内存持续占用或异常重启的风险。
- 优化 MQTT 命令去重与回执的内存占用，保留重复执行保护和冲突检查；修复 M1 改名后命令已执行、调用方却未收到确认的问题。
- M1 新增外接 BMP388／BMP390 气压传感器支持，可自动识别型号并在重新接入后恢复识别；在现有概览与设备摘要显示气压（hPa），失联或读数过期后自动隐藏，型号随探测结果更新。
- 修正绑定页面的 4 台设备上限，满额后禁止继续添加，并改善手机窄屏布局。

- 三款设备完成至少 4 小时只读 HTTP/MQTT 混合压力与恢复检查，未观察到非预期整机重启、死锁或持续内存增长；过载时可能返回 busy 或超时，降载后恢复。测试结论限于已测设备与负载，不保证所有情况均安全。
- 0.9.x 为 beta 版本，后续可能调整或移除功能、变更接口；请保留重要配置备份。
