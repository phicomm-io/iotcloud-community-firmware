- 新增 DAIKIN BRY88AX151K（ESP32）通用固件，共用本地网页、MQTT 与传感器会话协议；自动识别 PM2005 / PM2105 和可选甲醛模块，无甲醛模块时隐藏对应读数。DAIKIN 仅提供完整版。
- DAIKIN 空气质量页面采用单行传感器卡片、舒适度条和独立 PM10 卡片；显示 PM2.5、PM10、温湿度、CO₂、TVOC 与已连接设备。TVOC 提供 300 ppb 通风参考，指标胶囊固定大小并适配长文案。
- A1 自动化根据提供方实际可用的数据展示选项，不再依赖对方的设备型号；支持 DAIKIN 提供的数据，缺失或过期的数据不参与控制。原有绑定和联动配置保持兼容。
- A1、M1、TC1 在线下载改用内核 TLS，处理短读、短写和非阻塞等待，并限制握手、取消和总下载时间；失败和重试释放会话与 socket。HTTPS 仍不校验证书，OTA 固件签名继续强制验证。
- 修复 TC1 本地按键在低内存下因 JSON 状态查询失败而丢弃动作的问题；本地控制直接执行。另修复未配置 MQTT 主机时端口为 0 的默认配置不能通过配置接口恢复的问题。
- 官网 Release Log 增加中英文审核历史和跨版本升级差异，按型号、固件类型及实际发布链汇总；资料不足、翻译缺失或归档不一致时明确提示。旧 OTA 元数据、原始单版本说明、下载地址及固件文件保持兼容。
- 完整版设备的固件设置新增「查看升级差异」入口，将真实版本和固件类型带到官网；说明由浏览器计算，设备不保存发布历史，也不增加说明下载任务。官网可选读取一次内网设备信息，失败时仍可手动选择，密码不保存。
