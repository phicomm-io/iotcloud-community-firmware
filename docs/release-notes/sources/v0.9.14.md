- 优化设备内存占用，减少联动和 MQTT 通信的内存开销。A1 应用静态 RAM 减少约 10.8 KiB，TC1 减少约 1.0 KiB。
- A1、M1 的设备联动上限统一为 4 台。升级后，已有超过 4 台的联动配置仅启用前 4 台。
- 优化网页请求排队和 MQTT 命令回包，降低同时操作时的资源占用；设备繁忙或内存不足时可返回 busy，提示稍后重试。
- 增加内存余量和命令回包队列的诊断信息，方便排查设备繁忙问题。保留已有 Wi-Fi、MQTT、定时、按键和自动控制设置。
- 压缩 A1、M1、TC1 的内置网页，保留原有功能、中英文和操作方式，减少网页占用的固件空间。
- 提供完整版和精简版固件。完整版自带完整操作页面，可直接打开设备 IP 管理；文件名带 `no-frontend-resources` 的精简版保留离线配网、首次 MQTT 配置和网页密码设置，日常控制与完整设置通过本地设备管理页面或 IotCloud 使用。在线升级会保持当前固件类型。
- 完整版和精简版都支持内网管理：在本地设备管理页面填写设备内网 IP 和网页管理密码，即可直接操作，无需账号、后端或 MQTT 服务。浏览器需要允许访问本地网络。
- IotCloud 支持为设备配置内网地址，优先通过局域网连接；直连不可用时继续使用 MQTT，也可选择始终使用 MQTT。
