#### RC4：通信、网页与 S30-V1B

- **二进制业务接口。** HTTP、设备 MQTT、UDP 默认 MessagePack；移除旧 JSON 业务路径，仅 Home Assistant 保留精简 JSON。使用配套网页和支持发现协议的云平台；已有 JSON 脚本需要改造。
- **状态与诊断分离。** 业务状态按变化合并编码，无变化时复用缓存；通过 `diagnostics.get` 按需读取共用数字编号的诊断字段。MQTT 与 HA 分别记录发送进度，命令回执独立处理。
- **减少网页重复读取。** HTTP 串行合并、写优先及有限确认，取消过期只读请求并隔离旧响应。切换联动设置保留旧内容和未保存表单。A1 本地刷新动画，A1/M1 普通状态约 5 秒读取，操作后短时加快确认；不据此宣称新的 P95 收益。
- **认证与局域网联动。** 未设网页密码直接访问，不占登录会话；设密码后使用 token，保留 admin Basic。mDNS 发现、密码配对 UDP 与既有 MQTT 传感器会话授权并存。三款 MXCHIP 设备统一最多两个等待请求，过载有界返回。
- **迁移与构建。** 支持已识别的 0.9.x 配置布局，未知布局进入受保护恢复。前端按能力裁剪；MXCHIP 使用 GCC14 编译器及 GCC5 运行库，S30 使用 GCC5。容量、构建检查与实机稳定性分别验收。
- **S30-V1B 插座。** ORVIBO S30-V1B 使用 BL2028N/BK7231N/HLW8032，提供开关、电压、电流、功率、累计电量及持久化倍率设置。默认原厂分区布局，发布原生 RBL 和保留启动器的 STOCK_UA。原厂 `2M.1220` 首次网络安装及社区 URL OTA 已在测试机验证；首次安装须重新配网，不提供刷回原厂或双启动。其它原厂版本、标准仪表精度及断电恢复仍未验收。

#### 所有设备与平台

- **中英文界面与设备语言。** 设备操作页、配网页、平台界面、服务反馈和邮件支持简体中文 / English，保持原有界面风格。设备语言单独保存，决定 MQTT / Home Assistant 通告名称；浏览器语言独立设置，切换时不改变实体标识、唯一 ID 或主题。精简镜像保留配网页，完整操作页由独立前端提供。
- **本地连接按需展开。** 独立设备管理、平台和 Pages 演示均使用 Local connection 按钮，点击后才显示 IP、密码输入，可再次折叠。
- **完整配置备份与恢复。** 在有设备网页密码保护的局域网 HTTP 上下载或恢复完整配置，先核对机型、变体、配置版本及内容。保留已支持的旧配置迁移；不支持的布局保留原存储，确认后才清空恢复。M1 主控音乐、HomeKit 配对资料不在普通 Wi-Fi 配置备份中。
- **升级前直接核对差异。** TC1 / A1 / M1 设备更新页由浏览器获取并校验结构化发布资料，计算当前版本到目标版本的变化；资料不可用时说明原因，并在额外确认后才继续。
- **平台新账号适配 MQTT 主题限制。** 新用户名与 MQTT 别名限 3–32 个 ASCII 字母、数字、下划线、点或连字符；已有长账号保留登录，可添加短 MQTT 别名。邮箱登录独立处理，不改变设备连接第三方 Broker 的账号规则。平台服务单独部署，不随设备 OTA 更新。

#### M1：传感器、按键与双区域显示

- **独立显示两个固件版本。** 网页分别显示 Wi-Fi 模块与传感器 MCU 原始版本，无法读取时显示未知。原厂 **11.x 优先推荐开源主控；17.1.2.3 / 17.x 暂不建议迁移**。只升级 Wi-Fi 不会更新传感器 MCU。
- **更平稳的 PM2.5 与可选蜂鸣报警。** 配套开源主控使用三点中值和自适应平滑抑制尖峰，持续升高时快速跟随，并保留原始传感器帧查询。甲醛 / PM2.5 超阈值蜂鸣开关分别配置，默认关闭；不改变色灯、闹钟或手动提示音。网页提供开关并核对保存结果，旧主控明确提示能力限制。
- **单击、双击与分段长按。** 配套新主控后，单击开关屏幕；双击优先停止正在响铃的闹钟，否则按设置整体切换甲醛、PM2.5 两区的原始 / 用户读数。按住至少 3 秒、未满 10 秒松手，清除 Wi-Fi 和网页密码并保留 MQTT 等设置；按满 10 秒恢复联网模块出厂设置，主控独立音乐保留。保存成功后两颗 MCU 一起重启，离线也可操作。
- **两个区域分别选择数据。** 甲醛 / PM2.5 区域可同时配置本机传感器、经过配对的局域网设备或已授权 MQTT 传感器，或 API / 手动写入。来源包括外部 CO₂ 等传感器、大金读数、TC1 功率与 A1 主风机生效输出。两区各自配置有效期；缺失、过期、离线或无效时，仅相应区域恢复原读数，不改变物理采集或报警。
- **按固定玻璃选择数字和标识。** PM2.5 区域仅三位整数，最高 999；甲醛区支持整数、千位自动缩放、两位小数、一位小数末位补零、固定除以 1000。小数点固定在第一位之后。原厂字样和单位可分别显隐，玻璃仍只有 µg/m³、mg/m³，不会新增 ppm、W 或 % 字形。本机 / MQTT 正数溢出按所选模式上限显示。
- **每区九段灯独立设置。** 左、中、右三个位置各有红、绿、黄段，可以分别开关或同位置同时开多色；也可用两个阈值对显示转换前的原始物理值自动配色。
- **网页配置与原始 API。** 完整网页可设置两区的来源、有效期、数字格式、字样 / 单位、灯段和双击动作，提供固定玻璃预览及主控支持 / 确认状态。`display_profile.get/set` 使用 revision 校验，接受连续或带冒号、大小写均可的 MAC；先检查能力，保留原始 API / UART 及已定义配置迁移；旧 MQTT 数据和 HTTP 显示配置结构在 RC.1 中替换。`display_value.set` 对已设为 API 的区域直接写入 0–999 整数、小数点、标识和九段灯，不缩放、舍入、钳位或套用阈值；小数和越界数字拒绝，PM 不允许小数点，TTL 0 单独清除该区域。
- **主控镜像整包缓冲转发。** 支持的 Wi-Fi 固件先接收电脑完整上传的镜像，再由本机通过 UART 转发给传感器 MCU；原有电脑逐块 HTTP 桥接路径仍保留。主控独立升级，先检查设备能力与镜像要求；应用 OTA 保留原厂 Boot。原厂 11.x 所需工具、容量和运行条件见[主控升级教程](m1-mcu-update.html)。

#### TC1：向其他设备提供功率

TC1 为 M1 用户读数发布带设备身份、新鲜度和有效标记的功率数据。经局域网配对或已有 MQTT 传感器授权后可作为显示来源，不可用读数不会伪装成零。原有插口开关、定时和计量继续使用，未作为本次新增功能重复列出。

[TC1 操作与接入](tc1-guide.html)

#### A1：提供实际风机输出

A1 发布主风机当前生效输出 **0–100%**，包括新风变体，可供 M1 显示。该值不是 RPM，也不是尚未生效的请求档位；数据包含身份、新鲜度和有效标记，不可用时不伪装成零。A1 / M1 的 EMW3080 release 允许分配至保留 8 KiB，测试验收门槛仍为 12 KiB。

#### 大金：独立中枢版本

- **独立 hub 镜像与网页。** 在传感器功能上增加设备发现、配对、管理和中枢服务设置。自带 `/iotcloud/#/` 控制台配置上游 MQTT、巴法云和 HomeKit；不包含云端邮箱注册或 GitHub 登录。
- **mDNS 与 UDP 代替内置 Broker。** RC4 不再提供本地 MQTT TCP 1883 或 WebSocket Broker；中枢通过 mDNS 发现、配对 UDP 通信并转发上游 MQTT 与巴法云。本地 Home Assistant 及 MQTT 客户端统一连接外部 Broker，旧内置 Broker 配置需调整。
- **可选 HomeKit HAP 桥接。** 默认关闭的实验功能支持 TC1 六个 Switch、A1 风机 / 灯，以及 M1 / 大金的有效传感器。本机传感器也自动包含，**不包含 Matter**。
- **明确确认后切换中枢。** 已声明转换能力的 `full` 版本可使用容量匹配的签名 `hub` 镜像显式转换，保留联网配置。当前 rc.4 沿用 rc.1 的可选设备 Web 密码规则；最初 rc 的强制密码要求仅属于历史版本。普通 OTA 仍区分变体，不支持直接 `hub → full`。转换不会扩展当前 OTA 分区，必须核对实际槽容量。

#### 联网固件 v1.0.0-rc.1：通用字段与中枢更新

RC.1 在原候选版基础上增加以下变化：

- 设备通过传感器数据 schema 2 发布稳定字段 ID 及 `name/type/unit/value/valid/age_ms` 描述。当前数值类型为 `number`，无效读数使用 `null`，不伪装成零；TC1 功率、A1 主风机生效输出、M1 / 大金传感器采用同一契约。
- M1 显示配置 schema 4 按设备 + 字段 ID + 预期类型 / 单位绑定，不再按机型适配。来源设备新增匹配的数值字段，无需增加型号映射。新完整快照会立即撤销缺失、无效、不匹配或不支持类型的旧读数；空快照撤销全部旧候选，保留已保存绑定。协议预留未来类型，但不会将其转换成数字。自定义调用方需要迁移旧 RC 接口并使用配套前端。
- 设备 Web 密码改为可选：没有密码时允许中枢账户初始化和显式 full → hub 转换；已有密码仍必须通过 Basic `admin` 验证。独立中枢账户密码要求不变。
- 中枢设备列表自动首项展示只读本机，额外保留 12 个用户登记槽位，旧手工本机项仅在响应去重；不持久改写配置。禁止手工重复添加或删除本机。
- 控制台重启后通过只读请求恢复；旧会话返回 401 时回到登录，不重放配置写入或重启请求。

候选版的实际下载与已确认增量以[更新记录](release-log.html?channel=candidate)为准；IoTCloud 平台的独立版本不等于联网固件版本。

#### rc.2 继承修复与 rc.3 新增恢复手势

- **rc.2 配置与网页恢复修复继续保留。** M1 遇到不兼容配置时不会把仅重置网络误报为完整清空成功；完整和精简网页会刷新恢复状态，确认清空后等待重启并允许继续配网，完整网页的“重启与恢复”入口正常显示。未知第三方布局不因此获得自动迁移支持。
- **rc.3 新增 A1 备用恢复手势。** 对持续触摸约 2–3 秒就上报松开的面板，可短按 Wi-Fi 键两次、第三次按住 1–2 秒后松手重置网络；短按三次、第四次按住 1–2 秒后松手恢复出厂。每次短按须松手，相邻触碰间隔小于 0.3 秒，最后一次至少 1 秒、不足 5 秒；松手才执行，并绕过童锁。原 5 秒 / 10 秒恢复手势保留。新增手势尚未实机验收，详见 [A1 恢复说明](a1-guide.html#恢复手势)。
