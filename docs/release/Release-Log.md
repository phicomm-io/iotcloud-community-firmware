# Release Log

发布前在本 Wiki 编辑对应版本章节，再运行快照工具并提交到源码仓库。

## v1.0.0-rc.2

**RC 实际属于 Beta 测试版本，后续仍会有较大改动，不建议使用。** v1.0.0 的第三个候选版本，主要修复 M1 配置恢复和网页恢复入口，延续 rc.1 的功能与接口。

### M1 配置恢复

- 配置不兼容、需要确认清空时，仅重置网络不再误报成功或向主控发送成功确认。原始存储继续保留，需在网页明确确认完整清空后重新配网。
- 完整清空仍检查实际存储提交结果；提交失败保留恢复状态并允许重试，提交结果不确定时继续阻止写入。

### 网页恢复入口

- 修复完整网页“重启与恢复”页没有挂载内容、无法显示清空按钮的问题。
- 完整网页与精简配网页在恢复过程中重新读取配置状态，清空后等待重启并在重连后退出旧的迁移提示。同一页面即可重新配网，普通刷新保留尚未保存的输入。
- 清空请求提交后提示等待重启，防止重复提交；重启后仍需恢复时明确提示清空结果未确认，并允许重试。

### 范围与验证

- 本次修复不增加未知第三方配置布局的自动迁移支持。网页与实际 SDK 存储函数的主机回归已通过，反馈问题的 M1 仍待实机回归。
- A1 的 Wi-Fi 触摸按键长按无响应另行排查，本版不宣称修复该问题。

## v1.0.0-rc.1

v1.0.0 的第二个候选版本，延续已发布 v1.0.0-rc 的功能；本节列出通用数值来源、大金中枢与网页入口的增量。HomeKit 对本机传感器的支持沿用已发布 RC。

### 大金中枢管理列表

- 中枢自动出现在自己的设备列表，可直接查看本机传感器并进入设备设置。本机项不占用 12 个外部设备名额，也不能被当作外部设备删除或重复注册。

### 本地管理与版本转换

- 首次设置中枢及打开本地管理时，不再强制预先设置设备网页密码；已有网页密码时仍需正确鉴权。中枢本地账户的登录密码仍独立保留。
- 声明转换能力的新版 full，可在局域网网页选择匹配的 hub 签名包并明确确认切换，不再要求先设置网页密码；已有密码时仍需鉴权。机型、签名与实际 OTA 容量检查继续有效，转换保留联网配置；普通 OTA 继续隔离变体，不支持直接 hub → full OTA。

### HomeKit 状态显示

- 调整 HomeKit 开关或重置配对后，网页会在等待重启期间继续检查状态；服务恢复后显示当前状态，会话失效时提示重新登录。等待期间不重复提交开关或重置请求，也不显示过期配对码。

### 通用数值来源

- 设备以传感器数据 schema 2 发布任意字段 ID 及其名称、类型、单位、数值、有效标志和读数年龄（`name/type/unit/value/valid/age_ms`）。TC1 功率、A1 主风机生效输出、大金和 M1 的传感器读数均声明为 `number`；A1 输出为 0–100%，不是 RPM。无效数值使用 `null`，不以 0 代替。
- M1 显示配置 schema 4 按“设备 + 字段”选择来源，不再按设备型号适配。来源设备增加数值字段后，无需新增型号映射；M1 仅接受类型和单位匹配的 `number`。缺失、无效或 `unknown` 等非数值字段不再沿用旧读数；协议保留未来类型扩展。

读数沿用启动标识 `boot`、序号 `sequence` 和 `age_ms` 判断新鲜度，区分重启前后数据、重复消息及过期读数。

本版传感器数据采用 schema 2、M1 显示配置采用 schema 4，不兼容 v1.0.0-rc 的对应旧接口；自定义调用方需按 RC1 协议调整，并使用配套前端。

[查看自 0.9.27 以来的功能介绍、设备指南与下载](https://phicomm-io.github.io/)。候选版本与稳定版本分开展示；本节不替代已发布 v1.0.0-rc 的完整说明。

## v1.0.0-rc

v1.0.0 候选版本，包含设备固件、M1 传感器 MCU、WebUI 与云平台的配套更新。

### 通用与平台

- 设备网页、管理平台、配网页和服务反馈支持简体中文 / English。新增独立保存的设备语言，用于 MQTT / Home Assistant 通告名称；切换语言保留实体标识和主题。
- 保持原有界面风格；“Local connection”统一为按钮，点击后展开设备 IP 与密码输入。
- 云平台新用户名与 MQTT 别名限制为 3–32 个 ASCII 字母、数字、下划线、点或连字符。已有长账号保留登录，可添加短 MQTT 别名；邮箱登录独立处理。

### M1 传感器、按键与屏幕

- 分别显示 Wi-Fi 模块与传感器 MCU 版本，无法读取时显示未知。**原厂 11.x 优先推荐开源传感器 MCU；17.1.2.3 / 17.x 暂不建议迁移。** Wi-Fi OTA 不会同时更新传感器 MCU。
- PM2.5 加入尖峰抑制与自适应平滑，持续升高时快速跟随，保留原始传感器帧查询。
- 甲醛、PM2.5 超阈值蜂鸣报警可分别开启，默认关闭；与色灯、闹钟和手动提示音分别控制。
- 配套新版开源传感器 MCU 后，单击开关屏幕；双击优先停止闹钟，并可整体切换两个区域的原始 / 用户读数。按住 3 秒至未满 10 秒松手重新配网，保留 MQTT 等设置；按满 10 秒恢复出厂，保留主控独立音乐。保存设置后两颗 MCU 一起重启，离线也可操作。
- 甲醛与 PM2.5 两个区域可同时配置独立来源、有效期和颜色：本机传感器、同一 MQTT 账户 / Broker 下的其他传感器、TC1 功率、大金读数、A1 主风机生效输出百分比，以及 API / 手动写入。A1 输出是 0–100%，不表示 RPM。
- PM2.5 区域显示三位整数；甲醛区域支持整数、千位自动缩放、两位小数、一位小数末位补零、固定除以 1000。可分别显示或隐藏原厂字样及单位，每个区域的九段色灯可独立设置，也可按原始物理值的阈值自动配色。固定玻璃单位仍为 µg/m³、mg/m³。
- 新增 `display_profile.get/set` 与 `display_value.set` API。直接写入可指定 `0–999` 数字、小数点、字样、单位和完整九段灯；不套用来源转换或阈值配色，PM 区域不允许小数点。两路按有效期独立恢复原读数，支持立即清除与配置修订校验；新配置接受带冒号或连续形式的 MAC，大小写均可。

### 大金中枢版

- 新增独立 `hub` 变体，在大金传感器功能上提供本地账户、设备管理和中枢设置，可直接通过 WebUI 配置。
- 提供 MQTT TCP `1883` 和 WebSocket `9001/mqtt` Broker，局域网设备与 Home Assistant 可使用本地账户连接。中枢可同时作为上游 MQTT Client，按配置双向转发事件，并提供巴法云设备映射与转发。
- 提供可选的 **HomeKit HAP 桥接（实验功能，默认关闭）**：TC1 六路开关、A1 风机 / 灯，以及 M1 / 大金具备的有效传感器可接入 Apple 家庭。当前不包含 Matter。
- 支持从声明转换能力的新版 `full`，通过本地网页密码、匹配容量的签名 `hub` 镜像和明确确认切换为中枢，保留联网配置。普通 OTA 继续区分变体；不支持直接 `hub → full` OTA。

### 配置、升级与开发

- 增加受网页密码保护的局域网完整配置备份 / 恢复，先校验机型、变体和配置版本。保留已支持旧配置的迁移路径；不支持的配置进入需确认的恢复模式，保留原存储。M1 传感器 MCU 音乐、HomeKit 配对资料分别保存，不包含在普通 Wi-Fi 配置备份中。
- TC1 / A1 / M1 的设备升级页可直接查看并计算跨版本差异；资料不可用时说明原因并要求额外确认。M1 新显示能力先探测再启用，保留旧 API / UART 的兼容路径。
- A1 / M1 的 EMW3080 release 分配保留底线统一为 8 KiB，测试验收门槛仍为 12 KiB；允许在 8–12 KiB 区间正常分配。
- 整理 CI、Issue / PR 模板和贡献规范，明确接口、配置迁移与固定跨仓库依赖；归档 v0.9.x，维护代码采用 GPL-3.0，第三方许可保留。
- 用户文档继续按 M1 / A1 / TC1 / 大金组织安装、升级、使用和恢复入口，保持原有 Pages 风格；接口、协议、配置兼容性与样例集中发布到[开发者文档](https://phicomm-io.github.io/iotcloud-community-protocols/)。

- 一台 M1 已完成候选 Wi-Fi/MCU 网络升级、旧主控门控、真实网页写入与逐字读回、播放/停止、音乐闹钟到期停止及再次主控 OTA 后曲目保留；用户确认发声。原有连接、CO₂、阈值及定时配置保持，阈值表单写入/还原通过主机回归；未进行真实掉电中断、声压/示波器、长期稳定性或其他型号实机验收。

- 一台 DAIKIN 候选已完成两次 OTA、配置保留及网页单次 410 ppm 校准应答与后续读数观测；补偿公式通过主机参考值和范围检查。正式签名包、新温湿度补偿的实机对照精度、冷启动与长期稳定性尚未验收。本次不重发 M1 MCU v0.9.4，Wi-Fi OTA 不包含主控升级。
