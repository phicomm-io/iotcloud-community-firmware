# Release Log

发布前在本 Wiki 编辑对应版本章节，再运行快照工具并提交到源码仓库。

## v0.9.12

- A1 联动支持读取已绑定 M1 的 CO₂，可单独或与 PM2.5、甲醛组合用于固定、线性及 PID 自动调速；组合指标按最高需求调速，启停回差沿用任一启动、全部达标后待机的规则。
- CO₂ 独立判断有效期；未接 SCD40 的 M1 不参与 CO₂ 均值，所选 CO₂ 全部失效时使用离线风速，原有传感器过期不阻断仍有效的 CO₂。
- A1 为 CO₂ 发布 Home Assistant 标准二氧化碳实体（ppm），可通过 HA HomeKit Bridge 选入 Apple 家庭；已有固定导出白名单的用户需将新增 CO₂ 实体加入。
- SCD40 仅展示和转发 CO₂，不展示、不向 HA 转发 SCD40 自身温湿度；温湿度继续使用 M1 原有传感器。升级后自动清理此前发布的 SCD40 温湿度实体。
- 本地网页与 IotCloud 共用的 A1 页面支持 CO₂ 均值、组合指标及 ppm 阈值设置；保留 Wi-Fi、MQTT、绑定、定时、灯效、滤芯累计使用时间及其他已有配置。
- 包含 main 已有的 A1/M1 首次配网内存及网页响应修复，补齐网站图标、缓存重新验证和有界非阻塞 HTTP 响应，保留 dad0514 的首次刷入配置初始化修复。

## v0.9.11

- M1 支持外接 SCD40 二氧化碳传感器，通过 I²C 读取 CO₂ 浓度；使用 GPIO8 接 SDA、GPIO7 接 SCL，信号上拉至 3.3 V。接线说明见 M1 使用指南。
- 本地网页自动显示已检测到的 CO₂，将五项空气指标放入原有区域，统一标题与质量胶囊排布，并显示 CO₂ 舒适度范围。当前页面保留灰色过期读数，重新打开时隐藏过期 CO₂ 卡片。
- IotCloud 设备摘要同步显示新鲜 CO₂ 数据；Home Assistant 自动发现 CO₂ 实体，单位 ppm，读数过期后标为不可用，新读数到达后恢复。
- 保留 A1 从其他固件首次刷入时的配置初始化修复（dad0514），以及现有自动调速、电源键和配置迁移功能。
- 保留现有 Wi-Fi、MQTT、绑定与定时配置；未外接 SCD40 的 M1 保持原有四项显示。

## v0.9.10

- A1 默认电源键：关机时单击开机，开机时单击查看模式与当前实际风量，长按 1–4 秒后松手关机；双击继续切换自动／手动，保留电源状态。
- 查看状态先以青色双脉冲／暖橙色单脉冲提示自动／手动，再用同色风速条显示实际风量；开机状态不再叠加绿色按键灯效，仅关机后按键开机保留绿色提示；自动待机显示零风量，提示后恢复原灯效，遵守童锁和夜间亮度限制。
- 升级原默认电源键映射，保留已有自定义按键和其他设置；本地网页与管理平台可重新分配“开机／查看当前模式与风量”。
- 修复自动调速设置首次保存后未更新配置版本号，导致同一页面第二次保存失败的问题；同步中英文使用说明及 Wiki。

## v0.9.9

- A1 在 Home Assistant 中新增独立的中文“运行模式”选择器，自动／手动切换与电源独立，继续同步风扇预设模式和 HomeKit Bridge。
- 集中管理平台的自动调速卡片提供明确设置按钮，标题也可进入；读取期间立即显示提示，失败可重试，关机时仍能配置自动调速。
- 补充模式入口与 HomeKit Bridge 控制项刷新说明；保留 Wi-Fi、MQTT、绑定、风速、自动规则、滤芯、按键与定时设置。

## v0.9.8

- A1 自动与手动模式独立于电源，自动模式按空气质量调速，支持风速上下限、离线风速及独立夜间范围；手动关机后不会被空气质量联动打开。
- 新增可选启停回差：达到启动阈值后运行，降到目标值后待机，区间内保持原状态；支持 PM2.5、甲醛和组合指标，条件持续时间及最短运行／待机时间共同抑制频繁启停。运行期间按固定、线性或 PID 算法调速。
- 本地网页和集中管理平台均可切换模式、调整自动上限、设置目标与启动阈值；平台列表显示自动／手动及运行／待机／关机状态。
- 电源键默认双击切换自动／手动，模式设置以青色双脉冲／暖橙色单脉冲确认；Home Assistant 模式与 HomeKit Bridge 同步，保留电源状态与手动风速记忆。
- 保留 Wi-Fi、MQTT、绑定、滤芯、按键与定时配置；启停回差默认关闭，升级后可按需启用。

## v0.9.7

- A1 新增滤芯寿命预估：按风机运行时间累计，可调整额定寿命，并在更换滤芯后重置；设备页面、MQTT 和 Home Assistant 同步显示。
- A1 电源键、Wi-Fi 键和双键组合支持自定义连击及长按动作，包括灯效、风机、灯环、童锁、滤芯重置和重启；组合键避免误触单键及网络恢复。
- 改进 Home Assistant 中 A1 的中文名称、净化器图标和型号，绑定控制与滤芯实体显示在同一设备下；滤芯命令仍只作用于对应的物理 A1。
- 三型号统一使用 MiCO 3.6.4；修复 TC1 旧配置中未分配按键的迁移，恢复通用设置导航并改善触屏交互。
- 保留现有 Wi-Fi、MQTT、绑定、定时和按键配置；滤芯数据与新增组合键映射兼容迁移。

## v0.9.4

三型号签名 OTA 固件 v0.9.4，基于 main 提交 d50e937；与 v0.9.3 使用相同实现，本次更新版本号并由 CI 重新构建、签名。

- `.ota.bin.signed`：用于 MQTT/URL 和默认 Web 上传，强制验证 P-256/SHA-256 签名。

## v0.9.3

首个签名 OTA 版本，覆盖 TC1 A1、M1、A1。

- `.ota.bin.signed`：P-256/SHA-256 签名包，用于新固件 Web 默认上传及 MQTT/URL 安装。
- `.ota.bin.raw`：原生 OTA。旧固件首次过渡请通过可信本地 Web 上传；新固件勾选“允许未签名的固件”后即可上传，无二次弹窗。
- `.all.bin`：完整原生烧录镜像，不能把签名外壳交给 bootloader。

CI 私钥位于仓库外，并只在受 tag 限制的 GitHub 签名环境中使用；仓库只含公钥。设备擦除前验证头部签名，Flash 读回 SHA-256 和兼容性检查通过后才启用镜像。

M1 真机已验证 raw 过渡、Web raw/signed 上传、MQTT 坏签名/raw 拒绝及 signed 安装和重启恢复。TC1/A1 真机、完整资源峰值及断电/回退仍待验收。本版本允许重装和降级，URL 下载使用直接 HTTP 200 + Content-Length。

设计与验收记录：localdocs/ota-signed-update-v1.md；实现 PR #26。

发布后已下载三型号 Release 产物，逐一验证 P-256 签名、签名摘要及 SHA256SUMS。M1 另通过 MQTT 安装了本 Release 的 CI 签名包，重启后运行 0.9.3-d50e93，MQTT 与传感器数据恢复正常。


## v0.9.2

## M1 实机验证通过的可用版本

本次将 **v0.9.2** 记录为原装 EMW3080B / MK3080B 模块 M1 的实机验证可用基线。源码为 `c1c8f542eb1f61c34fbc12abca5aad681b7ff257`（PR #3），固件显示版本为 `0.9.2-c1c8f5`。

### 本次改动

- WebUI 首页展示实时空气信息及屏幕亮度，二级菜单管理 Wi-Fi、MQTT、设备、绑定联动、升级和诊断；切换页面保留未保存的输入。
- 修正 Wi-Fi 与错误图标的通道映射和熄灭输出：正常连接时 Wi-Fi 常亮、错误标志灭；Wi-Fi 故障时两者同步闪烁；已配置 MQTT 连接异常时 Wi-Fi 常亮、仅错误标志两长两短，未配置 MQTT 不报 MQTT 故障。
- 修复 MQTT 空闲超时误断线及 TCP 分包超过短 yield 期限引发的断线，增加错误计数与最近错误诊断。

### M1 验证记录（2026-10-14）

- 通过设备 Web API 完成 OTA，重启后恢复 Wi-Fi、MQTT 和有效传感器数据。
- 真实设备提供温度、湿度、甲醛、PM2.5 四项读数。
- 与 phicomm-community-mqtt 平台联调：账号主题自动发现、五项 HA 发现配置、网页亮度命令、设备设置值回执、独立 MQTT 客户端恢复亮度均通过；浏览器未出现页面错误。
- 独立 MQTT 客户端连续观察 66 秒，收到 14 次真实传感器上报，无离线事件；Broker 重启后的自动恢复已验证。该观察不代表长期稳定性测试。
- 用户已直接确认：短按屏幕亮灭正常；最终图标映射为 **Wi-Fi 常亮、错误标志灭**。
- 主机测试、WebUI 测试及三款固件 CI 构建通过。

实机验证最初使用同功能源码的开发构建（版本显示 `0.9.1-da45b9-dirty`）；Release 二进制由本标签 CI 构建，下载文件与校验值按本 Release 为准。

### 已知范围

- Wi-Fi/MQTT 故障闪烁时序通过主机测试，实物故障灯效尚未逐项观察验证。
- 实体长按重置、恢复出厂和重置网络尚未实现。
- M1 原屏幕甲醛/PM2.5 彩色指示灯的阈值和手动颜色控制尚无已验证协议，当前不支持。
- 本次实机可用结论只针对 M1；A1 空气净化器及 TC1（A1 硬件版本）附件通过构建，不代表本次完成其硬件验证。

### 下载

M1 网页升级请选择 **phicomm_m1.ota.bin**，不要上传 `.all.bin`；按 `SHA256SUMS` 核对下载文件。升级保留 Wi-Fi、MQTT 与亮度配置。
