# TC1 功能与操作

TC1 智能排插固件提供六路插座开关、计量、童锁、指示灯和定时任务。本文介绍安装后的日常操作；首次安装见[免拆图文教程](tc1-no-disassembly-ethernet-wifi-ap)或[有线刷机与恢复](tc1-flash)。

**日常使用推荐稳定版 v0.9.27。当前候选 v1.0.0-rc.3 实际属于 Beta 测试版本，后续仍会有较大改动，不建议日常使用。** 版本要求与累计变化见[候选版完整更新记录](release-log.html?channel=candidate)。

## 首页与插座控制

首页显示六路插座状态与总开关。每路插座可以单独开关，也可以用总开关一次控制全部。

| 元素 | 说明 |
| --- | --- |
| 六路插座 | 独立开关，可分别命名 |
| 总开关 | 一次开启或关闭全部插座 |
| 童锁 | 启用后阻止自定义按键动作 |

插座名称可以在网页中修改，设置会保存到设备。

## 计量与统计

TC1 提供用电计量与统计信息：

- **实时功率**：当前总功率。
- **电量统计**：累计用电量。
- **峰值与开启次数**：统计读数。
- **功率曲线**：首页以曲线呈现变化趋势。
- **上报间隔**：计量数据的上报周期可设置。

功率读数会应用设备侧的校准系数。若读数与独立计量设备存在固定偏差，可在设置中调整系数；建议先用稳定负载对比后再修改。

## 指示灯

TC1 使用指示灯呈现连接状态。**连接正常后恢复业务指示灯设置**，即连接异常提示优先于业务灯光。

指示灯可以按设置在业务状态下关闭或保持。连接状态的灯语规则是统一的，见[故障排查](faq#先看连接状态指示灯)。

## 定时任务

定时任务使用设备时区。设置 NTP 和时区后，确认时间已同步，再启用任务。

- 支持**按周**或**按日期**执行的任务。
- 任务可绑定到具体插座。
- 设备支持的任务条目有上限，列表分批加载。

详细的时间与定时说明见下。

## 时间与时区

定时任务依赖准确的设备时间：

1. 设置 NTP 服务器地址。
2. 设置设备时区。
3. 确认时间已经同步。

**夜间时段若结束时间早于开始时间，表示跨午夜。**

## 按键与恢复

TC1 支持自定义按键映射：

- **连击**：1–30 次，连击间隔结束后才执行动作。
- **长按**：1–4 秒。
- **5 秒及以上是保留区间**，不能作为自定义长按。

TC1 **没有默认的自定义按键动作**，需要自行配置。童锁会阻止自定义按键动作。可在按键设置中查看、修改和删除映射；相同的连续映射会折叠显示。

### 恢复手势

TC1 主按键保留恢复手势，在**松手时**执行：

| 按住时长 | 动作 |
| --- | --- |
| 5 秒至不足 10 秒 | 重置网络 |
| 至少 10 秒 | 恢复出厂设置 |

长按期间每满一秒给出短促灯光反馈，反馈不改变保存的业务灯光设置。**闪灯只反馈时间，不会提前执行恢复。**

> 操作前确认可以重新配网。出厂恢复会清除用户设置；**TC1 完整重置保留六路默认开启**。

恢复手势绕过童锁，普通物理动作受童锁约束。

## MQTT

TC1 保留 **Legacy（v1）** 与 **TMCP（v2）** 两种协议模式，首次配置 MQTT 时默认 TMCP。Home Assistant 接入与平台配置见 [MQTT 与联动](mqtt-link)。
