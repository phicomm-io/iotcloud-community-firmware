# 固件更新

本页说明已经运行社区固件后的网页 OTA 更新。原厂设备先按 [M1 原厂配网与安装](m1-no-disassembly) 或 [A1 原厂配网与安装](a1-no-disassembly) 等机型指南操作。M1 首次迁移须使用 0.9.21 起的完整版原生 OTA；原厂接口不使用社区签名包。

**日常使用选择稳定版 v0.9.27；v1.0.0-rc.5 用于 Beta 测试。** 测试候选时先阅读[完整累计说明](release-log.html?channel=candidate)，核对版本标签、型号和变体。候选包通过下载后手动安装，不会替换稳定 OTA 通道。

**M1 有两颗 MCU。** 本文更新的是 EMW3080 Wi-Fi 联网模块，不会同时更新与传感器通信的 ATSAMD20G18A 主控。双区域用户读数、双击等功能需配套开源主控 v1.0.0-rc；既有功能的最低版本见[主控功能与版本条件](m1-mcu-firmware)，独立升级按[主控网络升级教程](m1-mcu-update)操作。

## 通过设备网页在线检查

A1、M1、TC1 的正式构建提供 GitHub Pages HTTPS、境内 HTTP 和境外 HTTP 更新来源。在固件设置的更新页面选择来源后点击检查：

- 界面明确区分**发现新版本**、**已经是最新版本**和**网络失败**三种结果。
- 网络失败时可切换来源重试。
- 确认型号、版本和发布说明后，手动点击下载并安装。**设备不会因为检查更新而自动安装。**

可以直接查看所选版本的发布说明。下载中可点击「终止下载」；网络超时或下载失败后会恢复日常服务，重新开始时从头下载。进入最终提交阶段后不能终止。

## 查看跨版本升级差异

打开官网 [Release Log 的升级差异]({{SITE_URL}}guides/release-log.html?view=compare)，选择型号、固件类型、当前版本和目标版本。页面按发布链汇总累计变化，资料不全时会提示无法比较。

也可手动输入内网地址并读取一次设备信息。网页管理密码仅用于本次请求，读取失败仍可手动选择；查询不会检查或安装固件。旧设备的发布说明入口继续显示单版本原文。

## 完整版与精简版

DAIKIN BRY88AX151K 在 v1.0.0-rc.5 提供 `full` 普通版和独立的 `hub` 中枢版；两者均自动探测 PM2005 / PM2105 及可选甲醛模块。使用下文的本地文件升级，不提供在线检查或 URL 下载。普通 OTA 必须匹配当前变体；`full → hub` 仅通过[中枢切换流程](daikin-guide#普通版切换为中枢)操作，不支持直接 `hub → full` OTA。

默认文件是完整版，设备自带完整操作页面。文件名带 `-no-frontend-resources` 的精简版仍保留离线配网、首次 MQTT 配置和网页密码设置，可在设备热点或已联网地址打开；日常控制和完整设置通过[本地设备管理]({{SITE_URL}}local/)或 IoTCloud 使用。两种页面保持相同风格。

在线检查保持当前版本类型；手动切换版本类型时请选择同一产品的对应签名包。精简版不需要先配置 MQTT 才能配网。

## 选择正确的文件

下表适用于 A1、M1、TC1 和 DAIKIN。S30-V1B 使用 `.rbl` URL 下载升级，步骤见 [S30 升级](s30-guide#升级)。

下表适用于 A1、M1、TC1 和 DAIKIN。S30-V1B 使用 `.rbl` URL 下载升级，步骤见 [S30 升级](s30-guide#升级)。

下表适用于 A1、M1、TC1 和 DAIKIN。S30-V1B 使用 `.rbl` URL 下载升级，步骤见 [S30 升级](s30-guide#升级)。

| 文件 | 用途 |
| --- | --- |
| `.ota.bin.signed` | **签名 OTA 包**，用于网页上传与 MQTT/URL 安装，强制验证 P-256/SHA-256 签名 |
| `.ota.bin.raw` | 原生镜像，用于明确适配的首次迁移或无签名救援；M1 原厂迁移须使用 0.9.21 起的完整版 |
| `.all.bin` | **完整镜像，用于有线刷机。不要当作 OTA 上传** |

在 [项目主页与历史版本归档]({{SITE_URL}}#releases) 选择「本站归档（GitHub）」下载对应型号的文件，并按同版本 `SHA256SUMS` 校验。设备擦除前会验证头部签名，Flash 读回 SHA-256 与兼容性检查全部通过后才启用新镜像。

## 本地文件升级

A1、M1、TC1 和 DAIKIN 也可下载固件后，在设备网页上传安装：

1. 打开设备网页的固件更新页面。
2. 选择已校验的 `.ota.bin.signed` 文件并上传。
3. 等待写入和自动重启。**升级过程中保持供电。**
4. 重新访问网页，确认版本号已更新。

旧版社区固件的无签名救援可按对应流程使用 `.ota.bin.raw`；支持该功能的新固件在网页勾选「允许未签名的固件」后即可上传。原厂 M1 首次迁移使用独立的 [原厂上传步骤](m1-no-disassembly)，后续正常更新仍使用签名包。

## 失败处理

- 更新时暂停联动和其他业务响应，保留升级状态查询及终止。更新期间减少网页和 MQTT 并发访问。
- **网页仍可访问**：检查文件和网络后重试；确认型号与版本匹配。
- **设备无法启动**：按对应模块的下载器恢复方法处理，见各型号刷机文档。

各型号的刷机与恢复步骤：[TC1](tc1-flash) · [M1](m1-flash) · [A1](a1-flash) · [DAIKIN](daikin-guide)。
