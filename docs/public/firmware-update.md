# 固件更新

本项目固件支持网页 OTA 升级。**仅已经运行本项目固件的设备支持 OTA 流程；斐讯原厂固件或其他第三方固件必须先完成首刷**，不能直接套用 OTA 升级步骤。

## 通过设备网页在线检查

正式构建提供 GitHub Pages HTTPS、境内 HTTP 和境外 HTTP 更新来源。在固件设置的更新页面选择来源后点击检查：

- 界面明确区分**发现新版本**、**已经是最新版本**和**网络失败**三种结果。
- 网络失败时可切换来源重试。
- 确认型号、版本和发布说明后，手动点击下载并安装。**设备不会因为检查更新而自动安装。**

可以直接查看所选版本的发布说明。下载中可点击「终止下载」；网络超时或下载失败后会恢复日常服务，重新开始时从头下载。进入最终提交阶段后不能终止。

| 来源 | 地址 |
| --- | --- |
| GitHub Pages | `https://phicomm-io.github.io` |
| 境内镜像 | `http://phicomm.fjrcn.cn` |

## 选择正确的文件

| 文件 | 用途 |
| --- | --- |
| `.ota.bin.signed` | **签名 OTA 包**，用于网页上传与 MQTT/URL 安装，强制验证 P-256/SHA-256 签名 |
| `.ota.bin.raw` | 原始镜像，仅用于明确选择的无签名救援流程 |
| `.all.bin` | **完整镜像，用于有线刷机。不要当作 OTA 上传** |

在 [项目主页与历史版本归档]({{SITE_URL}}#releases) 选择「本站归档（GitHub）」下载对应型号的文件，并按同版本 `SHA256SUMS` 校验。设备擦除前会验证头部签名，Flash 读回 SHA-256 与兼容性检查全部通过后才启用新镜像。

## 本地文件升级

演示使用模拟数据。除在线来源外，也可以下载固件后在网页选择本地文件上传安装：

1. 打开设备网页的固件更新页面。
2. 选择已校验的 `.ota.bin.signed` 文件并上传。
3. 等待写入和自动重启。**升级过程中保持供电。**
4. 重新访问网页，确认版本号已更新。

从旧固件首次过渡时可能需要 `.ota.bin.raw`；新固件在网页勾选「允许未签名的固件」后即可上传，没有二次弹窗。

## 失败处理

- 更新时暂停联动和其他业务响应，保留升级状态查询及终止。为提高成功率，更新期间减少并发访问；持续多客户端压力更新尚未通过完整验收。
- **网页仍可访问**：检查文件和网络后重试；确认型号与版本匹配。
- **设备无法启动**：按对应模块的下载器恢复方法处理，见各型号刷机文档。
- **OTA 不需要拆机**。

各型号的刷机与恢复步骤：[TC1](tc1-flash) · [M1](a1-m1-flash) · [A1](a1-m1-flash)。
