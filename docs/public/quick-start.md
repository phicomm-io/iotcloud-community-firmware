# 快速开始

本项目为斐讯 TC1 智能排插、M1 空气检测仪和 A1 空气净化器维护社区固件，提供本地网页控制、MQTT 与 Home Assistant 接入。固件免费，无需厂商云服务。

## 先确认你的设备

| 设备 | 说明 | 硬件 |
| --- | --- | --- |
| **TC1 智能排插** | 六路插座开关、计量、童锁、指示灯和定时任务 | A1 硬件版本，EMW3031。**不支持 A2 硬件** |
| **M1 空气检测仪** | PM2.5、甲醛、温湿度读数和屏幕亮度设置 | 原装 EMW3080B / MK3080B，保留 ATSAMD20 |
| **A1 空气净化器** | 风机、灯环、童锁、夜间模式和与 M1 的联动 | 原装 EMW3080B / MK3080B |

> **`tc1(a1)` 指 TC1 的 A1 硬件版本，不是 A1 空气净化器。** 这是两个不同产品，固件文件不通用。刷写前务必确认型号。

如果你还没有安装本项目固件，请按对应型号的刷机文档操作：

- [TC1 刷机](tc1-flash)：EMW3031，J-Link 烧录
- [A1 / M1 刷机](a1-m1-flash)：EMW3080B，J-Link 或串口 Bootloader

## 首次配网

设备上电后若未配置 Wi-Fi，会开启配网热点。用手机或电脑连接该热点，浏览器访问 `http://192.168.0.1/` 完成配网。

| 设备 | 首次连接的热点 | 配网页面 |
| --- | --- | --- |
| TC1（A1 硬件版本） | `TC1-AP-<MAC后六位>` | `http://192.168.0.1/` |
| M1 | `M1-AP-<MAC后六位>` | `http://192.168.0.1/` |
| A1 空气净化器 | `A1-AP-<MAC后六位>` | `http://192.168.0.1/` |

热点名称中的 MAC 后六位为大写。旧版本的配网地址可能不同，请核对所选 Release 的版本说明。

## 访问设备网页

配网成功后，设备接入家庭 Wi-Fi。通过路由器查询设备的 DHCP 地址，在浏览器访问该 IP 地址即可打开 WebUI。

WebUI 顶部可切换中文、英文及明暗主题。设置按**网络、设备、自动化和维护**分组；修改配置后按保存，部分网络修改会断开连接。不同设备只显示所支持的功能。

主题选择保存在浏览器本地，与你在这台设备上的选择互通。
