# 故障排查

本页适用于社区固件。尚在原厂固件的 A1 / M1，请看[M1 原厂配网](m1-no-disassembly) / [A1 原厂配网](a1-no-disassembly)。

## 先看连接状态指示灯

TC1、M1、A1 和 DAIKIN 的连接异常提示**优先于**正常业务灯光：

**状态优先级：未配网 > Wi-Fi 断线 > MQTT 已配置但未就绪 > 正常**

| 状态 | 提示方式 |
| --- | --- |
| 未配置 Wi-Fi | 循环显示三长三短（三次 800 ms、三次 200 ms，相邻脉冲间隔 200 ms，末次后停顿 2000 ms） |
| Wi-Fi 未连接 | 约 **150 ms 亮、150 ms 灭**（快闪） |
| MQTT 已配置但未就绪 | 约 **1 秒亮、1 秒灭**（慢闪） |
| 正常 | 归还业务灯光控制 |

各设备的呈现位置：

- **TC1**：使用指示灯呈现连接状态，连接正常后恢复业务指示灯设置。
- **M1**：使用 Wi-Fi 图标与错误图标提示。正常时 Wi-Fi 图标常亮、错误图标灭。
- **A1**：使用灯环中的连接指示位置提示连接异常，其余灯光按配置呈现。
- **DAIKIN**：使用独立的 Wi-Fi 指示灯提示连接状态。

**S30-V1B** 的蓝灯表示插座输出；红灯表示 Wi-Fi 或已配置 MQTT 异常，未配网时红蓝交替。长按恢复提示优先于普通灯效，见 [S30 灯语](s30-features#红蓝指示灯)。

> **未配置 MQTT 不算 MQTT 连接故障。** 只有已经配置了 MQTT 但连接失败时才会提示。

## 常见问题

### 设备连不上，指示灯在快闪

Wi-Fi 未连接。确认路由器工作正常、密码正确，并检查是否超出了信号范围。可以按住按键重置网络后重新配网。

### 设备联网了，但灯在慢闪

已经配置的 MQTT 连接异常。检查 Broker 地址、端口、用户名和密码，以及服务器是否可达。**如果没有配置 MQTT，这不是故障。**

### 找不到设备的 IP 地址

在路由器的 DHCP 客户端列表中查找设备 MAC 对应的地址。配网热点只在未配置 Wi-Fi 时开启；已经联网的设备不会再开热点。

### 忘记网页密码

**TC1 主按键 / S30-V1B 按键 / A1 Wi-Fi 键：按住 5 秒至不足 10 秒后松手重置网络；按住至少 10 秒后松手恢复出厂设置。** 出厂恢复会清除用户设置，需要重新配网。

**M1 保留原厂主控时：按住机身按键 9 秒以上后松开**，清除 Wi-Fi 和网页密码并重启，保留其他用户设置。

### 按键没有反应

- 童锁会阻止自定义按键动作，先确认童锁已关闭。
- TC1 / A1 自定义按键动作在**松手后**才识别；恢复操作也在松手后执行，且不受童锁屏蔽。
- **5 秒及以上是保留区间**，不能作为自定义长按。
- 连击需要等连击间隔结束后才执行。

### A1 联动不工作

按顺序检查：

1. A1 是否已填写正确的数据源 MAC 与可选 IP；M1、DAIKIN 无需填写配对标识。
2. 数据源成员与联动规则是否已配置并启用。
3. 双方是否使用新版固件、同一 MQTT 服务和账号，Broker 是否允许通用传感器主题；检查局域网 UDP 及 MQTT 测量是否可用。
4. 所选指标是否有有效读数；缺失指标会隐藏其选项，无有效数据时为 `null` 并使用离线风速。

### 升级失败

升级过程中必须保持供电。若网页仍可访问，检查文件和网络后重试；若设备无法启动，按对应型号的刷机文档用下载器恢复：[TC1](tc1-flash) · [M1](m1-flash) · [A1](a1-flash) · [DAIKIN](daikin-guide) · [S30-V1B](s30-flash)。

### 配置没有保存

部分网络修改会断开连接，需要重新访问设备网页确认。也可以检查设备是否在保存过程中断电。

## 恢复出厂设置的影响

恢复出厂会清除用户设置。TC1 完整重置保留六路默认开启。恢复后需要重新配网。

**恢复操作前请确认你能够重新配网**（知道 Wi-Fi 密码、设备在可覆盖范围内）。
