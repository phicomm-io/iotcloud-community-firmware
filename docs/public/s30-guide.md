# S30-V1B 功能与操作

**ORVIBO S30-V1B** 是单路计量插座，使用 BL2028N 模块、BK7231N 芯片和 HLW8032 计量芯片。本固件沿用项目统一的首页、设置导航、主题和语言切换；项目名为 `iotcloud`，协议名为 `openiot`。首次安装见 [S30-V1B 拆机刷机](s30-flash)。

已在原电源及真实负载下验证计量收帧、实时读数与累计电量增长。默认系数尚未经过标准仪表校准，不声明计量精度；请勿将当前读数用于计费或安全保护判断。

## 配网与访问

1. 未配置网络时，连接 `S30M_V1B_XXXXXX` 热点；`XXXXXX` 是本机工厂 MAC 后六位的大写十六进制。初始热点无需密码。
2. 浏览器打开 **http://192.168.0.1**，在设置中填写可用的 **2.4 GHz Wi-Fi** 名称和密码并保存。
3. 设备重启并联网后，将手机或电脑切回同一局域网，在路由器中找到设备获得的 IP，再用浏览器打开该地址。路由器中显示的主机名为 `iotcloud-s30-v1b-xxxxxx`，后缀为 MAC 后六位的小写形式。

初始网页管理密码为空，直接进入页面，不需要登录。设置管理密码后才需要认证；使用 HTTP Basic 的客户端用户名为 `admin`。管理密码独立于 Wi-Fi 密码和 MQTT 账号密码。忘记管理密码需要恢复出厂设置，仅重置 Wi-Fi 不会清除它。

## 开关与设置

首页提供一路插座开关及计量读数。短按设备按钮也可切换输出，蓝灯随输出通断。童锁开启后屏蔽短按，但仍可通过网页控制及使用长按恢复手势。

设置中可修改设备名称、插座名称、上电开关策略、指示灯、童锁、上报间隔、Wi-Fi、MQTT 和管理密码。默认上电关闭；重启后按保存的上电策略执行，不一定恢复重启前的临时开关状态。短按后的约 1.5 秒内，远程开关可能返回忙，避免立即覆盖本地操作。

## 红蓝指示灯

下表为普通指示灯启用时的含义：

| 状态 | 蓝灯 | 红灯 |
| --- | --- | --- |
| Wi-Fi 正常，MQTT 未配置或已连接 | 输出开启常亮，关闭熄灭 | 熄灭 |
| 已配网但 Wi-Fi 断开 | 继续表示输出通断 | 快闪，亮灭各约 150 ms |
| Wi-Fi 正常，已配置 MQTT 但未就绪 | 继续表示输出通断 | 慢闪，亮灭各约 1 秒 |
| 未配置网络且未联网 | 红蓝交替，每色约 500 ms | 与蓝灯交替 |

关闭指示灯设置会关闭上述普通状态灯效。按住按钮时，计时提示优先显示，且不受指示灯关闭或童锁影响。

## 按键与重置

| 操作 | 松手后的动作 |
| --- | --- |
| 短按 | 切换插座输出；童锁开启时忽略 |
| 按住 1 秒至不足 5 秒 | 无重置动作 |
| 按住至少 5 秒、不足 10 秒 | 重置 Wi-Fi 并重启 |
| 按住至少 10 秒 | 恢复出厂设置并重启 |

长按灯语与 TC1 保持相同节奏：**从按满 1 秒起，每满一秒闪一次、亮约 160 ms**。第 1–4 次为蓝灯，第 5–9 次为红灯，第 10 次起红蓝同步。松手后恢复普通灯效；重置在松手时执行，按到 5 秒时不会立即重启，因此可以继续按住进入 10 秒手势。

Wi-Fi 重置清除主、备用网络，保留产品设置、MQTT、管理密码、配对、校准系数和累计电量。出厂恢复同时清除这些设置及累计值，回到默认上电关闭状态。重置后重新连接设备热点配网。

## 计量读数

HLW8032 提供电压、电流、有功功率及累计电量。收到有效采样才显示相应实时值；缺失或超过约 5 秒未更新的采样显示为无数据，不能把它解释为负载功率为零。

默认电压、电流、功率系数分别为 `1.88 / 1 / 1.88`，只是初始值。校准时需要稳定负载与独立参考仪表分别核对，负载铭牌或估算瓦数不能作为精度依据。累计电量约每 5 分钟保存一次，保存配置及正常重启前也会保存；突然断电可能丢失最近约 5 分钟的累计量。

若输出已经开启但仍无计量数据，先检查状态中的计量有效性，不要通过随意放大系数制造读数。涉及计量线路检查时，先断电并移除负载，恢复串口或外接直流供电前必须断开市电。

## MQTT 与 Home Assistant

在设置中填写 MQTT broker 地址、端口和所需账号密码。当前支持 TCP MQTT。Home Assistant 可发现一路插座、电压、电流、功率、累计电量及计量有效性六个实体；未配置 MQTT 不影响本地网页使用。

HTTP、MQTT 和 UDP 业务采用项目 `openiot` 的 MessagePack / CBOR 二进制协议，JSON 仅用于 Home Assistant。协议主题、配对权限和接口见仓库 `BL2028N/README.md`。网页管理密码为空不代表取消 MQTT broker 认证或 UDP 配对。

## 固件更新

安装本固件后，可在网页的升级设置中输入**本设备 `.rbl` 文件的 HTTP 下载地址**。设备必须能够直接访问该地址；下载文件与同版本校验值应来自可信来源。升级期间暂停 MQTT、UDP、扫描及新的控制/配置操作，保留 HTTP 状态查询；失败后恢复服务，成功后自动重启。重启后的插座输出按已保存的上电策略执行，请先确认负载允许中断和重新供电。

当前没有网页本地文件上传，也没有数字签名验证。其他设备的 `.ota.bin` 签名包不能用于本设备，RBL 的完整性校验也不等于签名认证。首次安装仍按[拆机刷机](s30-flash)操作。
