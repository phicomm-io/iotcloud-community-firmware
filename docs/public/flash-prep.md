# 刷机前准备

这一页是所有型号首刷的**通用要求**。先读完这页，再进入对应型号的操作步骤。型号文档只写各自的差异，供电、接线和模块接口在这里统一说明。

## 安全要求（务必先读）

拆机和连接下载器前**断开市电、原电源及负载**。

烧录时：

- 仅使用**独立、稳定的 3.3V 电源**。
- **不要让市电与电脑下载线同时连接。**
- **不要把 5V 接到模块供电或信号引脚。**

完整镜像会覆盖原固件及部分设置。需要恢复原厂时，**应事先保存本机 Flash 备份**，不能用其他设备的备份替代——备份中含有本机参数。

> 错误示例：把 J-Link 标准 20 针接口的 19 针（5V 输出）接到模块。**VTref 是电压检测输入，不是 3.3V 电源输出。**

## 选择对应型号的步骤

| 设备 | 模块 | 首刷方式 | 文档 |
| --- | --- | --- | --- |
| TC1 智能排插 | EMW3031 | J-Link + FlashPlus 完整地址烧录 | [TC1 刷机](tc1-flash) |
| M1 空气检测仪 | EMW3080B / MK3080B | **优先**保留原 Bootloader 的 YMODEM 首刷 | [M1 刷机](m1-flash) |
| A1 空气净化器 | EMW3080B / MK3080B | 完整地址烧录 | [A1 刷机](a1-flash) |

**TC1 的 A1 硬件版本与 A1 空气净化器是两个产品**，固件文件必须按产品选择。

## 固件文件类型

| 文件 | 用途 | 用于首刷？ |
| --- | --- | --- |
| `.all.bin` | 完整原生烧录镜像 | 是（完整地址烧录） |
| `.ota.bin.signed` | 签名 OTA 升级包 | 否，仅用于已运行本项目固件的设备 |
| `.ota.bin.raw` | 原始 OTA 镜像 | 否，仅用于无签名救援流程 |

**网页升级使用 `.ota.bin`，不要上传 `.all.bin` 或 `.usr.bin`。** 下载后按同版本 `SHA256SUMS` 校验。

## EMW3080B：模块接口（M1 / A1）

M1 和 A1 使用**相同的模块烧录接口**，但固件文件必须按产品选择。本节适用于**保留庆科 Bootloader、能进入串口下载模式**的原装 EMW3080B，不适用于更换后的其他模块。

### 需要的工具

- 支持 3.3V 电平和 **921600 波特率**的 USB-TTL 转换器
- 独立 3.3V 电源
- 导线、焊接工具
- 支持 Ymodem 的串口软件（例如 SecureCRT）

### 接线

按模块引脚编号连接，**TX / RX 交叉**。不要把日志串口当作下载串口。

| EMW3080B 模块引脚 | 连接 |
| --- | --- |
| 16：VCC | 独立电源 3.3V |
| 17：GND | 电源负极和 USB-TTL GND，共地 |
| 9：用户 UART TX | USB-TTL RX |
| 10：用户 UART RX | USB-TTL TX |
| 19：BOOT | 进入下载模式时接 GND，完成后解除 |

![庆科官网 EMW3080B 引脚图](assets/images/emw3080-pins.png)

[查看庆科官网引脚图（原图）](https://docs.mxchip.com/img/zh/1631842737419-34af0113-6807-499a-9ff9-129040293369.png)。**编号方向以该图为准**，勿把模块翻面后直接照搬左右位置。

### 进入下载模式

1. **断电接线**，将 BOOT（19）拉低。
2. 打开串口软件，选转换器对应的 COM 口，设置 **921600、8N1、无流控**。
3. 再给模块上电。

看到 Bootloader 命令提示后才能继续。**没有提示时先检查供电、共地、TX/RX 和 BOOT，不要盲目发送烧录命令。**

### 模块相关的注意事项

- **M1**：保留原传感器控制器；烧录期间若主板也在驱动模块 RX，应隔离该串口的另一端输出，避免两个 TX 同时驱动一根线。
- **A1**：烧录时断开原电源和风机连接。
