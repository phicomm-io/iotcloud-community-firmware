# DAIKIN 自动化、联动与远程显示

## 传感器联动与中枢

普通版提供本机有效的传感器数据；可在 A1 配置实际 ID，通过授权后的局域网会话参与自动调速，也可通过下面的 MQTT 传感器字段供 M1 显示。没有安装的甲醛模块不提供有效甲醛值，CO₂ 预热及过期读数不会伪装为零。

中枢是独立固件变体，通过 mDNS 发现设备，配对后使用 UDP 通信，并转发至上游服务。本地 HA／MQTT 使用外部 broker。配置见 [中枢版本](daikin-guide#中枢版本)。

## 设备 ID 与字段 ID

`device_id` 使用本机工厂 MAC 的 12 位小写十六进制形式，如 `aabbccddeeff`。在设备信息／诊断页查看实际 ID，或从同一 MQTT 账户的设备列表中选择。字段 ID 大小写敏感，按下表填写。

| 字段 ID | 含义 | 单位 |
| --- | --- | --- |
| `temperature` | 温度 | `°C` |
| `humidity` | 湿度 | `%` |
| `pm25` | PM2.5 | `µg/m³` |
| `pm10` | PM10 | `µg/m³` |
| `co2` | CO₂ | `ppm` |
| `tvoc` | TVOC | `ppb` |
| `formaldehyde` | 甲醛（可选模块） | `mg/m³` |

## 通过 MQTT 供 M1 显示

1. 来源设备与 M1 都配置为项目二进制 MQTT 模式，连接**同一个外部 broker、同一个 MQTT 账户**。该账户的 ACL 需要允许读取自己的传感器主题。仅填相同服务器、使用不同账号，通常不能互相发现。
2. 在 M1「设置 → 常规 → 设备屏幕用户读数」中选择甲醛区域或 PM2.5 区域，来源选「其他 MQTT 设备」。选择实际来源设备和字段；找不到时先确认两端都支持传感器字段协议并已上报。
3. 保存来源、单位、显示方式和有效时间，启用用户读数；需要时按已配置的双击动作整体切换原始／用户读数。默认有效时间为 20 秒；超过有效时间或收到无效值时，该区域回到原始读数。
4. 网页、云平台可关闭。只要两台设备与 broker 正常运行，来源发布、M1 订阅和显示继续工作。

M1 是三位数的固定段码屏，不能显示任意单位文字。PM2.5 区域只显示整数；甲醛区域的小数点固定在第一位后。显示 W、V、A 或 ppm 等外部数据时，按需要隐藏原来的「甲醛／PM2.5」字样及 mg/m³、µg/m³ 单位。超量程与显示方式见 [M1 操作说明](m1-guide#v1-候选版用户读数与-pm25-稳定处理)。

## 协议与排查

传感器字段描述和数值采用 **MessagePack schema 3**，分别通过 `metadata` 和 `state` 发布。主题为 `phicomm/v2/u_<账户编码>/sensor/<device_id>/metadata` 与 `/state`；账户编码由固件按用户名生成，空用户名使用本地作用域。元数据保留，数值不保留；启动标识、序号、字段版本、有效标志与读数年龄用于拒绝旧数据。调试工具需支持 MessagePack 解码。

设备离线、字段不存在、单位不匹配或读数过期时，检查来源上报与 M1 有效期。无效或缺失数据按不可用处理。内网 UDP 配对、网页管理认证与 MQTT broker 认证相互独立。开发者接口见 [openiot 协议文档]({{PROTOCOLS_URL}})。
