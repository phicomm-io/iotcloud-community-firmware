# M1 空气检测仪 功能与操作

M1 固件提供 PM2.5、甲醛、温湿度读数，屏幕亮度设置，并可作为 A1 空气净化器的联动数据源。本文介绍安装完成后的日常操作；首次安装见 [M1 刷机](m1-flash)。

## 首页读数

首页展示实时空气质量信息：

| 读数 | 说明 |
| --- | --- |
| **PM2.5** | 颗粒物浓度 |
| **甲醛** | 甲醛浓度 |
| **温度** | 环境温度 |
| **湿度** | 相对湿度 |

界面按读数等级给出颜色与文字判定（优 / 良 / 差等）。

## 屏幕亮度

屏幕亮度可在网页中调整，设置会保存到设备并进行回执确认。也可以通过 MQTT 命令调整亮度，独立 MQTT 客户端修改后设备会回传设置值。

## Wi-Fi 图标与错误图标

M1 使用原面板上的两个图标提示网络状态，**它们是独立输出**：

| 状态 | Wi-Fi 图标 | 错误图标 |
| --- | --- | --- |
| 正常 | 常亮 | 灭 |
| Wi-Fi 故障 | 闪烁 | 闪烁 |
| 已配置 MQTT 连接异常 | 常亮 | 两长两短 |

关闭输出时对应 GPIO 切换为低电平。**未配置 MQTT 不报 MQTT 故障。**

> M1 原屏幕的甲醛 / PM2.5 彩色指示灯的阈值和手动颜色控制尚无已验证协议，当前不支持。

## 按键与恢复

M1 使用**原面板的 `0x18` 长按事件**，发送固定 `0x16` ACK，单次启动去重后清除 Wi-Fi 和网页密码。

M1 不支持像 TC1 / A1 那样精确的 5 / 10 秒分段恢复手势，也**没有自定义按键映射**——不要套用 A1/TC1 的按键设置。硬件恢复的详细步骤见 [M1 刷机](m1-flash)。

完整重置可以在 M1 的 WebUI 中执行。

## 作为 A1 的联动数据源

M1 只检测、上报并应答**已授权**的 A1，不主动控制净化器，也不主动轮询 A1。

- 在 M1 的绑定设置中添加 `A1_MAC:M1_MAC` 配对标识。
- 许可列表最多八个并去重。
- M1 会拒绝联动通道上的配置读写、解绑和传感器推送。

绑定与联动规则见 [MQTT 与联动](mqtt-link#a1-与-m1-联动)。

## MQTT

M1 固定使用 **TMCP（v2）** 主题，不提供 Legacy 模式选择。Home Assistant 接入与平台配置见 [MQTT 与联动](mqtt-link)。
