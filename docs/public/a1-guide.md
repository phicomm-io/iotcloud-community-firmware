# A1 空气净化器 功能与操作

A1 固件提供风机调速、灯环、童锁、夜间模式，以及与 M1 空气检测仪的自动联动。本文介绍安装完成后的日常操作；首次安装见 [A1 刷机](a1-m1-flash)。

## 风机与开关

首页提供电源开关与风机档位控制。

- **电源**：开启或关闭净化器。
- **手动模式**：按设定风速运行；切回手动时恢复上次手动风速。
- **自动模式**：开机后根据 M1 的空气质量读数调速，可选择 PM2.5、甲醛或两者中需求更高的一项。
- **模式与电源独立**：关机时可以切换模式，但不会因此开机。关闭电源后，空气变差也不会主动开启。
- **滑环与网页滑块**：手动模式调整风速，自动模式调整当前时段的最高风速；操作风速会同时开机。

在自动调速设置中配置最低、最高及传感器离线风速。最低风速设为 **0%** 时，空气良好可停转待机；电源仍保持开启，空气变差后恢复运行。待机与恢复使用防抖和最短切换间隔，避免频繁停转。

固定、线性与 PID 三种调速策略均保留。传感器未绑定、离线或读数过期时，使用设定的离线风速，并限制在当前时段的风速范围内；有效读数恢复后继续自动调速。离线策略不会打开已关闭的电源。

夜间每个时段可独立设置最低、最高与离线风速，调速算法与白天相同。重叠时段按列表中最后匹配的一项执行；手动模式仍受夜间风速上限约束。时钟尚未同步时使用白天设置。

## 滤芯寿命预估

首页显示剩余寿命百分比和累计使用小时。仅在风机有运行输出时累计，待机、停机不计时；手动、定时、夜间和自动联动均适用，各档风速按相同时间计入。

默认额定寿命为 **4320 小时**，相当于连续运行 180 天。该值是本功能的估算基准，可展开“调整额定寿命”，按所用滤芯规格设置为 1–20000 小时。修改额定寿命不会清除已用时间。常见滤芯的更换周期会随环境和使用方式变化，可参考[厂商的寿命说明](https://www.mi.com/global/support/article/KA-06874/)；本功能不检测滤芯堵塞或污染程度，请结合滤芯状况判断。

剩余寿命不超过 10% 时提示建议更换，耗尽后显示 0%，仍可正常控制风机。**更换新滤芯后**点击“更换滤芯后重置”，确认后清零已用时间并恢复为 100%，额定寿命设置保留。

使用时间会保留至下次启动：运行中每累计一小时保存一次，风机停止、正常网页重启或升级前也会保存。突然断电可能丢失最近不足一小时的计时。网络重置保留滤芯计时，恢复出厂设置会清空计时并恢复默认额定寿命。首次升级到此功能时从零开始，无法还原此前滤芯使用时间。

## 灯环

灯环呈现空气状态、连接进度和操作反馈。

选择模式成功后，**自动模式为青色双脉冲，手动模式为暖橙色单脉冲**，约 1.2 秒后恢复原灯效。网页、按键和 Home Assistant 的模式操作均有提示；重复选择同一模式也会确认。关机或关闭业务灯光时仍短暂提示，不会因此启动风机或更改灯光设置；夜间亮度上限仍生效。

| 设置 | 说明 |
| --- | --- |
| 空气质量灯光 | 按读数呈现颜色 |
| 分段灯带 | 分段显示范围 |
| 颜色与量程 | 自定义颜色和对应量程 |

**连接异常提示优先于业务灯光**：A1 在业务灯效渲染后再覆盖故障灯，并服从夜间亮度上限。连接正常时归还业务灯控制权。灯语规则见[故障排查](faq#先看连接状态指示灯)。

## 童锁与夜间模式

- **童锁**：阻止普通按键动作，避免误触；已配置的童锁开关手势仍可用于解锁。
- **夜间模式**：在设定时段内降低亮度。夜间时段若结束时间早于开始时间，表示跨午夜。

## 与 M1 联动

**联动配置集中在净化器端**。M1 只负责检测和应答。

在 A1 中：

1. 配置 M1 成员（添加已授权的 M1）。
2. 设置自动模式的风速范围、离线风速、调速策略、防抖与最短切换间隔。
3. 选择自动模式并打开电源。没有可用读数时使用离线风速。

A1 对已绑定且 15 秒内有效的 M1 数据计算实时算术平均；**没有有效数据时读数为 `null`**。

A1 发起会话初始化、探测和查询，优先走局域网，失败回退 MQTT。M1 重启后 A1 会周期重新初始化会话，不需要重填令牌。

> 双方需要一起升级。完整绑定步骤见 [MQTT 与联动](mqtt-link#a1-与-m1-联动)。

## 按键与恢复

A1 有两个按键：**电源键**和 **Wi-Fi 键**。默认电源键单击切换电源，双击切换自动／手动模式。升级时保留已有自定义双击动作；可在按键设置中重新分配。

在 **设置 → 自动化 → 按键事件** 中选择电源键、Wi-Fi 键或双键组合，再选择手势与动作。双键组合需要同时触碰两个按键；组合触发后不会再执行本轮单键动作，错开松手也不会触发 Wi-Fi 恢复。

自定义按键映射支持：

- **连击**：1–30 次，连击间隔结束后才执行动作。
- **长按**：1–4 秒。
- **5 秒及以上是保留区间**，不能作为自定义长按。

可配置的动作包括：轮换灯效、选择指定灯效、重置滤芯寿命、风机开关和风速、灯环开关和亮度、灯环常亮、童锁及重启。开关类动作支持开启、关闭和切换；灯环切换可保留原亮度。相同的连续映射会折叠显示。长按动作在松手时执行。

### 滤芯寿命

按键事件页可查看滤芯用量、修改额定寿命或在换芯后清零，也可将清零绑定到按键手势。计时和估算规则见上方“滤芯寿命预估”。

### 恢复手势

**A1 Wi-Fi 键**保留恢复手势，在**松手时**执行：

| 按住时长 | 动作 |
| --- | --- |
| 5 秒至不足 10 秒 | 重置网络 |
| 至少 10 秒 | 恢复出厂设置 |

长按期间每满一秒给出短促灯光反馈，反馈不改变保存的业务灯光设置。**闪灯只反馈时间，不会提前执行恢复。** 恢复手势绕过童锁。

> 操作前确认可以重新配网。出厂恢复会清除用户设置。

A1 的 WebUI 也提供完整重置。

## MQTT

A1 固定使用 **TMCP（v2）** 主题，不提供 Legacy 模式选择。Home Assistant 接入与平台配置见 [MQTT 与联动](mqtt-link)。


## Home Assistant 与 HomeKit 模式

Home Assistant 的净化器实体提供 `auto` 与 `manual` 模式，网页、机身按键和 HA 切换后会同步状态；关闭电源后仍保留所选模式。HA 的风速操作进入手动模式并设定风速；网页与机身滑环在自动模式下调整上限。

若 HomeKit 中仍显示为普通风扇，请在已有 HomeKit Bridge 的 `entity_config` 中将 A1 设置为 `air_purifier`，实体 ID 换成 HA 中的实际名称：

```yaml
entity_config:
  fan.your_a1:
    type: air_purifier
    linked_pm25_sensor: sensor.your_a1_pm25
```

PM2.5 关联项可选；未绑定 M1 时可以省略。配置方式参见 [Home Assistant HomeKit Bridge 文档](https://www.home-assistant.io/integrations/homekit/)。

通过 HomeKit Bridge 暴露为空气净化器时，HomeKit 的自动模式对应 HA 的 `auto`。当前 HA 桥接在选择手动时会发送风速命令，因此会进入手动并应用 HomeKit 显示的风速；这条风速命令在关机时也可能开启电源。若要恢复上次手动风速并保留关机状态，请直接选择 HA 或网页中的手动模式。桥接可能把零风速待机显示为净化中或最低风速，设备的实际待机状态以网页为准。
