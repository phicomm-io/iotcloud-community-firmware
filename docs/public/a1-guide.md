# A1 空气净化器 功能与操作

A1 固件提供风机调速、灯环、童锁、夜间模式，以及与 M1 空气检测仪的自动联动。本文介绍安装完成后的日常操作；首次安装见 [A1 刷机](a1-m1-flash)。

## 风机与开关

首页提供电源开关与风机档位控制。

- **电源**：开启或关闭净化器。
- **手动模式**：按设定风速运行；切回手动时恢复上次手动风速。
- **自动模式**：开机后根据 M1 的空气质量读数调速，可选择 PM2.5、甲醛，以及支持 CO₂ 的 M1 所提供的 CO₂；组合多个指标时按需求最高的一项调速。
- **模式与电源独立**：关机时可以切换模式，但不会因此开机。关闭电源后，空气变差也不会主动开启。
- **滑环与网页滑块**：手动模式调整风速，自动模式调整当前时段的最高风速；操作风速会同时开机。

在自动调速设置中配置最低、最高及传感器离线风速。最低风速设为 **0%** 时，空气良好可停转待机；电源仍保持开启，空气变差后恢复运行。待机与恢复使用防抖和最短切换间隔，避免频繁停转。

集中管理平台首页的“自动调速设置”按钮和自动调速标题均可打开设置。读取期间显示提示，连接失败时可重试。Home Assistant 的 A1 设备中提供独立的“运行模式”选择器，选择“自动”或“手动”不会改变电源；风扇详情的预设模式也可切换。HomeKit Bridge 使用风扇的 auto/manual 预设同步模式。升级后若家庭 App 仍显示旧控制项，可在 HA 中重新加载 HomeKit Bridge，再重新打开家庭 App。

可选开启 **启停回差**，分别设置目标值和更高的启动阈值。例如 PM2.5 目标为 35、启动阈值为 50：达到 50 后运行，降到 35 后停转待机，35～50 之间保持原状态。刚开机时若读数处于两者之间则待机。所选指标中任一项达到启动阈值即可运行，全部降到目标值才待机。条件需连续满足设定时间，每次启停还受最短运行／待机时间限制。

运行时继续按所选固定、线性或 PID 算法调速；PID 使用相同目标值。启用回差后，运行时最低为 1%，待机时为 0%，不受最低风速限制。夜间风速上限仍生效；调整风速上限或切换夜间时段会保留启停状态。关闭回差后恢复持续调速逻辑。设备本地网页和 MQTT 远程集中管理平台均可显示模式、运行／待机状态，并修改这些设置。

固定、线性与 PID 三种调速策略均保留。传感器未绑定、离线或读数过期时，使用设定的离线风速，并限制在当前时段的风速范围内；有效读数恢复后继续自动调速。离线策略不会打开已关闭的电源。

夜间每个时段可独立设置最低、最高与离线风速，调速算法与白天相同。重叠时段按列表中最后匹配的一项执行；手动模式仍受夜间风速上限约束。时钟尚未同步时使用白天设置。

## 滤芯寿命预估

首页显示剩余寿命百分比和累计使用小时。仅在风机有运行输出时累计，待机、停机不计时；手动、定时、夜间和自动联动均适用，各档风速按相同时间计入。

默认额定寿命为 **4320 小时**，相当于连续运行 180 天。该值是本功能的估算基准，可展开“调整额定寿命”，按所用滤芯规格设置为 1–20000 小时。修改额定寿命不会清除已用时间。常见滤芯的更换周期会随环境和使用方式变化，可参考[厂商的寿命说明](https://www.mi.com/global/support/article/KA-06874/)；本功能不检测滤芯堵塞或污染程度，请结合滤芯状况判断。

剩余寿命不超过 10% 时提示建议更换，耗尽后显示 0%，仍可正常控制风机。**更换新滤芯后**点击“更换滤芯后重置”，确认后清零已用时间并恢复为 100%，额定寿命设置保留。

使用时间会保留至下次启动：运行中每累计一小时保存一次，风机停止、正常网页重启或升级前也会保存。突然断电可能丢失最近不足一小时的计时。网络重置保留滤芯计时，恢复出厂设置会清空计时并恢复默认额定寿命。首次升级到此功能时从零开始，无法还原此前滤芯使用时间。

## 灯环

灯环呈现空气状态、连接进度和操作反馈。

选择模式成功后，**自动模式为青色双脉冲，手动模式为暖橙色单脉冲**，约 1.2 秒后恢复原灯效。网页、按键和 Home Assistant 的模式操作均有提示；重复选择同一模式也会确认。关机或关闭业务灯光时仍短暂提示，不会因此启动风机或更改灯光设置；夜间亮度上限仍生效。

| 设置 | 说明 |
| --- | --- |
| 空气质量灯光 | 按读数呈现颜色 |
| 呼吸与彩虹跑马灯 | 在“设置 → 灯光效果”调整变化速度，1–10 档由慢到快；默认第 5 档，保存后下次启动仍生效 |
| 分段灯带 | 分段显示范围 |
| 颜色与量程 | 自定义颜色和对应量程 |

**连接异常提示优先于业务灯光**：A1 在业务灯效渲染后再覆盖故障灯，并服从夜间亮度上限。连接正常时归还业务灯控制权。灯语规则见[故障排查](faq#先看连接状态指示灯)。

## 倒计时关闭

进入“设置 → 定时任务”，选择“倒计时关闭”，填写小时和分钟后保存，可设置 1 分钟至 24 小时。到时关闭净化器，手动与自动模式均适用。任务列表显示剩余时间，可取消，也可重新计时；重新计时从设定的完整时长开始。

倒计时无需网络校时，关闭网页后仍继续。设备断电或重启后会取消，不会自动重新开始。倒计时与普通定时共用 8 个任务名额；到时若设备忙，列表会标记跳过，不重复执行。每周和指定日期的任务仍需完成校时。

## 童锁与夜间模式

- **童锁**：阻止普通按键动作，避免误触；已配置的童锁开关手势仍可用于解锁。
- **夜间模式**：在设定时段内降低亮度。夜间时段若结束时间早于开始时间，表示跨午夜。

## 与 M1 联动

若绑定的 M1 已接入 SCD40，A1 首页会显示平均 CO₂（ppm），自动调速设置可选择 CO₂ 或与 PM2.5、甲醛组合使用。A1 与 M1 均需升级到支持 CO₂ 联动的固件。CO₂ 使用独立有效期：未安装传感器的 M1 不参与 CO₂ 统计；选择 CO₂ 后若所有 CO₂ 读数缺失或过期，则使用离线风速，不会把缺失读数当成 0。只选择 PM2.5／甲醛时不受 CO₂ 失效影响。

CO₂ 默认启动阈值为 1500 ppm、待机目标为 1000 ppm，线性调速范围为 800–2000 ppm，可自行调整。多个指标组合时，任一达到启动阈值即可运行，全部回到各自目标值才进入待机。

**联动配置集中在净化器端**。M1 只负责检测和应答。

在 A1 中：

1. 添加 M1 的 MAC 与可选 IP，最多四台；M1 无需配置。
2. 设置自动模式的风速范围、离线风速、调速策略、防抖与最短切换间隔。
3. 选择自动模式并打开电源。没有可用读数时使用离线风速。

A1 对已绑定且 15 秒内有效的 M1 数据计算实时算术平均；**没有有效数据时读数为 `null`**。

A1 通过 MQTT 发送会话 token，之后只通过局域网 UDP 查询。UDP 不通时使用离线风速并退避重试；M1 重启后 A1 会自动重新授权，不需要手动填写 token。

> 双方需要一起升级。完整绑定步骤见 [MQTT 与联动](mqtt-link#a1-与-m1-联动)。

## 按键与恢复

A1 有两个按键：**电源键**和 **Wi-Fi 键**。默认电源键操作如下：

| 手势 | 操作 |
| --- | --- |
| 关机时单击 | 开机，保留原自动／手动模式 |
| 开机时单击 | 查看当前模式及风量，继续保持开机 |
| 双击 | 切换自动／手动模式，保留电源状态 |
| 长按 1–4 秒后松手 | 关机 |

查看状态时，灯环先以**青色双脉冲表示自动、暖橙色单脉冲表示手动**，约 1.2 秒后，用相同颜色的风速条显示当前实际风量约 3 秒。自动待机时风量为零，模式提示后风速条熄灭；显示的是实际风量，不是自动风速上限或记忆的手动风速。提示结束后恢复原灯效，业务灯光关闭时也能临时查看，夜间亮度上限仍生效。开机状态下按电源键不再叠加绿色按键灯效；只有关机后按键开机时保留绿色灯条。查看操作不改模式、风速或灯光设置，童锁开启时不执行。

升级时将原默认的单击电源切换改为“开机／查看当前模式与风量”，并为未分配的电源长按设置关机动作；已有自定义单击、双击、长按和组合动作保留。可在按键设置中重新分配。

在 **设置 → 自动化 → 按键事件** 中选择电源键、Wi-Fi 键或双键组合，再选择手势与动作。双键组合需要同时触碰两个按键；组合触发后不会再执行本轮单键动作，错开松手也不会触发 Wi-Fi 恢复。

自定义按键映射支持：

- **连击**：1–30 次，连击间隔结束后才执行动作。
- **长按**：1–4 秒。
- **5 秒及以上是保留区间**，不能作为自定义长按。

可配置的动作包括：开机／查看当前模式与风量、轮换灯效、选择指定灯效、重置滤芯寿命、风机开关和风速、灯环开关和亮度、灯环常亮、童锁及重启。开关类动作支持开启、关闭和切换；灯环切换可保留原亮度。相同的连续映射会折叠显示。长按动作在松手时执行。

### 滤芯寿命

按键事件页可查看滤芯用量、修改额定寿命或在换芯后清零，也可将清零绑定到按键手势。计时和估算规则见上方“滤芯寿命预估”。

### 恢复手势

**A1 Wi-Fi 键**保留恢复手势，在**松手时**执行：

| 按住时长 | 动作 |
| --- | --- |
| 5 秒至不足 10 秒 | 重置网络 |
| 至少 10 秒 | 恢复出厂设置 |

长按期间每满一秒给出短促灯光反馈，反馈不改变保存的业务灯光设置。**闪灯只反馈时间，不会提前执行恢复。** 恢复手势绕过童锁。

> 操作前确认可以重新配网。出厂恢复会清除用户设置。

A1 的 WebUI 也提供完整重置。

## MQTT

A1 固定使用 **TMCP（v2）** 主题，不提供 Legacy 模式选择。Home Assistant 接入与平台配置见 [MQTT 与联动](mqtt-link)。


## Home Assistant 与 HomeKit 模式

Home Assistant 的净化器实体提供 `auto` 与 `manual` 模式，网页、机身按键和 HA 切换后会同步状态；关闭电源后仍保留所选模式。HA 的风速操作进入手动模式并设定风速；网页与机身滑环在自动模式下调整上限。

若 HomeKit 中仍显示为普通风扇，请在已有 HomeKit Bridge 的 `entity_config` 中将 A1 设置为 `air_purifier`，实体 ID 换成 HA 中的实际名称：

```yaml
entity_config:
  fan.your_a1:
    type: air_purifier
    linked_pm25_sensor: sensor.your_a1_pm25
```

PM2.5 关联项可选；未绑定 M1 时可以省略。配置方式参见 [Home Assistant HomeKit Bridge 文档](https://www.home-assistant.io/integrations/homekit/)。

通过 HomeKit Bridge 暴露为空气净化器时，HomeKit 的自动模式对应 HA 的 `auto`。当前 HA 桥接在选择手动时会发送风速命令，因此会进入手动并应用 HomeKit 显示的风速；这条风速命令在关机时也可能开启电源。若要恢复上次手动风速并保留关机状态，请直接选择 HA 或网页中的手动模式。桥接可能把零风速待机显示为净化中或最低风速，设备的实际待机状态以网页为准。

### M1 读数与 Home Assistant / HomeKit

M1 通过自己的 MQTT 连接发布传感器实体，包括温湿度、PM2.5、甲醛以及已安装扩展传感器的 CO₂ 和气压。HomeKit Bridge 可以选入这些实体。A1 使用 M1 读数进行联动，并在自己的状态中提供需要的均值；A1 不再发布各台 M1 的代理传感器实体。升级时会清理旧代理实体的发现配置。

## 可选新风风机

从 v0.9.23 起，可选择 `fresh-air`（含网页）或 `fresh-air-no-frontend-resources`（不含网页资源）版本。普通 A1 无需更换到新风版。升级时选择与当前变体匹配的镜像；新风版会占用用户串口，不能同时用作串口通信。

连接兼容的 PWM 风扇：用户串口 TX（GPIO9）接 PWM 控制输入，RX（GPIO10）接转速反馈，信号地共地。风扇电源由匹配其额定电压、电流的电源提供，不能从信号引脚取电。接线前核对风扇接口定义及信号电平，必要时使用电平转换；不要将风扇电源接入 TX/RX。原风机驱动板接线不变，两路 PWM 均为 25 kHz。

首页可单独开关新风、设置速度或自动模式。在“新风”设置中选择 PWM 开启极性，设置输出上下限及映射参数。正向预设随速度提高占空比，反向预设随速度提高降低占空比；停机不受运行占空比下限限制。转速以 RPM 显示，每转脉冲数默认 2，应按风扇规格修改；反馈仅供显示，不提供失速保护。

调速关系可选择：

- 独立调速：两路不受比例限制。
- 比例限制：新风指令不超过原风机指令乘以设定比例。
- 抬高原风机：原风机指令至少为新风指令乘以设定比例；原风机达到自动或夜间上限时，相应限制新风。

这里的比例针对设定百分比，不是实际 RPM 的比例。整机关机停止两路。原风机与新风的自动策略在同一“自动调速”页面分别设置和保存，PM2.5、甲醛、CO₂ 可以多选，至少保留一项；CO₂ 需要可用的对应传感器数据。

正常重启和升级前会停止输出，但断电开机及引导阶段的关机电平尚不能保证。如需上电期间始终停转，请使用适合所选极性的外部上下拉或使能电路，并实际测量确认。
