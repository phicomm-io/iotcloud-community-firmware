# A1 空气净化器 功能与操作

A1 固件提供风机调速、灯环、童锁、夜间模式，以及与 M1 空气检测仪的自动联动。本文介绍安装完成后的日常操作；首次安装见 [A1 刷机](a1-m1-flash)。

## 风机与开关

首页提供电源开关与风机档位控制。

- **电源**：开启或关闭净化器。
- **风机档位**：手动选择风速。
- **自动**：按 M1 的读数与联动规则自动调整。

## 滤芯寿命预估

首页显示剩余寿命百分比和累计使用小时。仅在风机有运行输出时累计，待机、停机不计时；手动、定时、夜间和自动联动均适用，各档风速按相同时间计入。

默认额定寿命为 **4320 小时**，相当于连续运行 180 天。该值是本功能的估算基准，可展开“调整额定寿命”，按所用滤芯规格设置为 1–20000 小时。修改额定寿命不会清除已用时间。常见滤芯的更换周期会随环境和使用方式变化，可参考[厂商的寿命说明](https://www.mi.com/global/support/article/KA-06874/)；本功能不检测滤芯堵塞或污染程度，请结合滤芯状况判断。

剩余寿命不超过 10% 时提示建议更换，耗尽后显示 0%，仍可正常控制风机。**更换新滤芯后**点击“更换滤芯后重置”，确认后清零已用时间并恢复为 100%，额定寿命设置保留。

使用时间会保留至下次启动：运行中每累计一小时保存一次，风机停止、正常网页重启或升级前也会保存。突然断电可能丢失最近不足一小时的计时。网络重置保留滤芯计时，恢复出厂设置会清空计时并恢复默认额定寿命。首次升级到此功能时从零开始，无法还原此前滤芯使用时间。

## 灯环

灯环呈现空气状态、连接进度和操作反馈。

| 设置 | 说明 |
| --- | --- |
| 空气质量灯光 | 按读数呈现颜色 |
| 分段灯带 | 分段显示范围 |
| 颜色与量程 | 自定义颜色和对应量程 |

**连接异常提示优先于业务灯光**：A1 在业务灯效渲染后再覆盖故障灯，并服从夜间亮度上限。连接正常时归还业务灯控制权。灯语规则见[故障排查](faq#先看连接状态指示灯)。

## 童锁与夜间模式

- **童锁**：阻止自定义按键动作，避免误触。
- **夜间模式**：在设定时段内降低亮度。夜间时段若结束时间早于开始时间，表示跨午夜。

## 与 M1 联动

**联动配置集中在净化器端**。M1 只负责检测和应答。

在 A1 中：

1. 配置 M1 成员（添加已授权的 M1）。
2. 设置联动开关、阈值、风速策略、防抖与最短切换间隔。
3. 确认平均读数有效后启用。

A1 对已绑定且 15 秒内有效的 M1 数据计算实时算术平均；**没有有效数据时读数为 `null`**。

A1 发起会话初始化、探测和查询，优先走局域网，失败回退 MQTT。M1 重启后 A1 会周期重新初始化会话，不需要重填令牌。

> 双方需要一起升级。完整绑定步骤见 [MQTT 与联动](mqtt-link#a1-与-m1-联动)。

## 按键与恢复

A1 有两个按键：**功能键**和 **Wi-Fi 键**。默认功能键单击切换风机。

自定义按键映射支持：

- **连击**：1–30 次，连击间隔结束后才执行动作。
- **长按**：1–4 秒。
- **5 秒及以上是保留区间**，不能作为自定义长按。

童锁会阻止自定义按键动作。相同的连续映射会折叠显示。

### 恢复手势

**A1 Wi-Fi 键**保留恢复手势，在**松手时**执行：

| 按住时长 | 动作 |
| --- | --- |
| 5 秒至不足 10 秒 | 重置网络 |
| 至少 10 秒 | 恢复出厂设置 |

长按期间每满一秒给出短促灯光反馈，反馈不改变保存的业务灯光设置。**闪灯只反馈时间，不会提前执行恢复。** 恢复手势绕过童锁。

> 操作前确认可以重新配网。出厂恢复会清除用户设置。

A1 的 WebUI 也提供完整重置。

## MQTT

A1 固定使用 **TMCP（v2）** 主题，不提供 Legacy 模式选择。Home Assistant 接入与平台配置见 [MQTT 与联动](mqtt-link)。
