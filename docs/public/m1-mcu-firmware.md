# M1 主控开源固件：让屏幕与蜂鸣器有更多玩法

这份开源固件运行在 M1 的传感器主控上，当前源码采用 GPL-3.0 许可。更新前，请先确认自己要刷的是哪颗芯片。

**兼容性：推荐原厂主控 11.x 使用开源固件。原厂 17.1.2.3 / 17.x 差异较大，尚待分析，暂不建议迁移。** 请读取传感器主控的实际版本，不要根据 Wi-Fi 版本推断；无法读取时按未知处理。

## 先分清：M1 里有两颗 MCU

MCU 就是设备里的微控制器。M1 有两颗，**固件和版本号分别管理**：

| 本站称呼 | 芯片与用途 | 怎么更新 |
| --- | --- | --- |
| **Wi-Fi MCU / 联网模块** | EMW3080：连接 Wi-Fi、提供本地网页、通过 MQTT 联网 | 使用普通网页“固件更新”，选择 M1 Wi-Fi 固件 |
| **传感器主控 / 主控 MCU** | ATSAMD20G18A：与机内传感器通信，控制屏幕、按键和蜂鸣器 | 电脑脚本通过 API 烧录，使用 `m1-mcu-ota.bin` 及配套 JSON |

**本文的“主控”均指与传感器通信的那颗 MCU。** Wi-Fi 升到 v1.0.0-rc.3，不代表传感器主控也升级了。为降低新手选错镜像、刷坏设备的风险，传感器主控升级没有提供 WebUI 上传按钮；请按[通过 API 网络升级传感器主控](m1-mcu-update)操作，由脚本完成 API 通信与校验。

**日常使用推荐稳定联网固件 v0.9.27。RC 实际属于 Beta 测试版本，后续仍会有较大改动，不建议日常使用。** 测试 v1 功能时分别安装 **Wi-Fi v1.0.0-rc.3 与传感器主控 v1.0.0-rc**，用于双区域用户读数、双击与 PM2.5 稳定处理。旧版功能的最低兼容条件仍保留：四种提示音、自定义 RTTTL 音乐需要主控 v0.9.3 或更新版本；颗粒物详情与原始传感器帧需要主控 v0.9.4 发布的相应能力。实体屏幕显示 CO₂ 需要主控 v0.9.2 或更新版本，并提供有效的 CO₂ 数据。只使用原有 PM2.5、甲醛、温湿度读数，无需为此额外刷主控。

## 相比原厂增加了什么

原有 PM2.5、甲醛、温湿度、时钟与亮度控制仍是基础。下面是开源主控增加的扩展；网页入口还需要配套联网固件按主控真实版本与能力开放。

| 能力 | 开源主控带来的变化 | 最早版本与兼容条件 |
| --- | --- | --- |
| 在实体屏幕显示 CO₂ | 可替换甲醛或 PM 数字位置，或按秒交替显示；过期后恢复原读数，支持 CO₂ 灯色阈值 | v0.9.2；需要外接传感器及联网模块提供有效 CO₂ 数据，原机不会凭空测出 CO₂ |
| 屏幕与蜂鸣器调试 | 数值覆盖、29 字节段 RAM 查询/写入、全段点亮、PWM 频率与时长控制，到期恢复正常显示 | v0.9.2；通过新增 0x70 扩展协议 |
| 查询能力与运行状态 | 查询传感器健康、显示缓存、PM 模式和当前阈值，便于排查数据与屏幕差异 | v0.9.2；配套工具或联网固件 |
| 四种提示音 | 轻触、确认、提示、错误四种单次音，由主控负责到期停止 | v0.9.3 开发预览；配套 Wi-Fi v0.9.27 |
| 自定义 RTTTL 音乐 | 写入、读取、播放、停止一首单音曲目；主控 Flash 双槽保存，重启和正常应用 OTA 后保留；配套 WebUI 可作闹钟曲目 | v0.9.3 开发预览；配套 Wi-Fi v0.9.27；最多 1024 字节、256 音符、180 秒 |
| 完整传感器帧读取 | 两套 PM1.0/PM2.5/PM10、六档累计颗粒数、甲醛原始值、温湿度原始字与状态；带帧龄、健康和校验信息 | 主控 v0.9.4；Wi-Fi v0.9.27 已支持 WebUI 读取，也可用电脑工具查询 |
| 可审阅的升级与恢复实现 | 开源接收/暂存/校验流程；独立新 Boot 增加 CRC32 日志与中断后重新搬运 | 仅替换独立 Boot 后才有新 Boot 的校验与恢复行为；CRC 不是签名，也不是旧版回滚 |

自定义污染阈值控制指示灯颜色，并可查询当前配置。高等级蜂鸣告警可按甲醛、PM2.5 分别开启，默认关闭。

## 下载与使用条件

测试 v1 功能使用 **主控 v1.0.0-rc，属于 Beta 候选 / 预发布版本**，v1.0.0 稳定版尚未发布。镜像来自该 Release，运行版本为 `1.0.0-rc-97a03b`；升级工具需按[网络升级教程](m1-mcu-update)取得含缓冲转发的固定版本，不能用该 RC 标签内的旧工具替代。原厂 11.x 网络迁移需配套 Wi-Fi v1.0.0-rc.3，并核对 `mcu_ota_max_bytes` 缓冲能力。

旧版兼容条件：已经运行社区主控时，网络升级与完整帧工具查询可使用 Wi-Fi v0.9.26 或更新版本；网页音乐、提示音和颗粒物详情最低需要 Wi-Fi v0.9.27，并满足对应的主控能力要求。这些最低版本不替代原厂 11.x 的缓冲升级要求。下载区单独列出主控全部公开 Release（含 Pre-release），与联网固件归档分开；主控与联网模块需要分别升级。


- `m1-mcu-ota.bin`：主控应用，链接地址 **0x4000**，配套 JSON 与 SHA256SUMS 一起核对。
- `m1-mcu-debug-recovery.zip`：应用/Boot 调试与恢复产物，各镜像地址见包内说明。
- 主控应用升级不替换原厂 Boot。保留原厂 Boot 时不能获得新 Boot 的 CRC 与中断恢复保证。
- 主控镜像不能填入 EMW3080 联网模块的固件更新地址。配套升级路径见[主控网络升级](https://github.com/phicomm-io/phicomm_m1_mcu_atsamd20/blob/main/docs/network-ota.md)。

## 读取更多传感器数据

测试组合 **Wi-Fi v1.0.0-rc.3 + 传感器主控 v1.0.0-rc**（旧版最低为 Wi-Fi v0.9.27 + 主控 v0.9.4 完整帧能力），打开 M1 本地网页首页，找到**“颗粒物详情”**卡片即可查看 PM1.0、PM10 和六档累计颗粒数；PM2.5 仍在原来的主读数卡片中。展开详情可查看 CF=1 浓度及原始传感器诊断。“两套”指大气环境与 CF=1 两种浓度口径，不是装了两个颗粒物传感器；“六档累计颗粒数”指每 0.1 L 空气中，大于各粒径门槛的颗粒数量，不是六个独立浓度。

**网页读取不需要运行电脑命令。** 未支持、预热、故障或读数过期时，不能把缺失数据当成 0；不可用的测量值显示“—”。新增读数也支持 MQTT 上报与 Home Assistant 自动发现，见 [M1 功能与操作](m1-guide)。

如需用电脑查询，主控 v0.9.4 搭配 Wi-Fi v0.9.26 或更新版本即可。先按[升级教程](m1-mcu-update)取得配套源码工具，再填写自己的设备 IP 和设备 ID：

## 原厂主控备份

提供 **ATSAMD20G18A 原厂 11.1.2.1 主 Flash 备份**，仅用于匹配硬件的开发与恢复。文件为 256 KiB（262144 字节）。它包含原厂 Boot 与应用，**不包含 NVM User Row、熔丝和校准辅助区，也不是联网模块固件**。

[下载原厂主控备份](assets/firmware/m1-mcu/m1-atsamd20g18a-stock-11.1.2.1.bin) · [SHA256SUMS](assets/firmware/m1-mcu/SHA256SUMS)

```text
SHA-256 6a8a9f72741e01d5ebc73467819079146553ec73339029eaf4cc49e8cbd1a7f9
```

整份备份对应主 Flash 起始地址 **0x00000000**，不能作为应用 OTA 负载。恢复前先保存自己设备的备份，核对芯片与板卡、供电和 SWD 恢复条件；不要将这份备份用于不同主控版本或硬件修订。原厂二进制作为原厂备份单独提供，不属于本项目 GPL-3.0 开源代码。

## v1.0.0-rc 功能

v1.0.0-rc 已加入双击事件、通用 Wi-Fi 数值显示与 PM2.5 稳定处理。配套联网固件可选择其他在线设备的 CO₂ 数据，并管理单位、阈值和有效期；过期后恢复原始显示，闹钟响铃时双击优先取消闹钟。这是预发布版本，需要配套主控、联网固件和前端。

甲醛与 PM2.5 可分别设置超阈值蜂鸣报警，默认关闭、按需开启。色灯阈值、闹钟和手动鸣叫分别控制，不受该开关影响。
