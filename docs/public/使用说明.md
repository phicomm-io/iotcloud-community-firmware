# 使用说明

## 三款设备

TC1 提供六路插座开关、计量、童锁、指示灯和定时任务。M1 提供 PM2.5、甲醛、温湿度读数和屏幕亮度设置。A1 提供风机、灯环、童锁、夜间模式和与 M1 的联动。

在设备所在局域网访问其 IP 地址。WebUI 顶部可切换中文、英文及明暗主题。设置按网络、设备、自动化和维护分组；修改配置后按保存，部分网络修改会断开连接。不同设备只显示所支持的功能。

## 灯语与连接状态

连接异常提示优先于正常业务灯光。未配置 Wi-Fi 时循环显示三长三短提示；Wi-Fi 未连接时约 150 ms 亮、150 ms 灭；Wi-Fi 已连接且已配置的 MQTT 未就绪时约 1 秒亮、1 秒灭。未配置 MQTT 不算 MQTT 连接故障。

- TC1 使用指示灯呈现连接状态，连接正常后恢复业务指示灯设置。
- M1 使用 Wi-Fi 图标与错误图标提示网络和 MQTT 状态；连接正常时 Wi-Fi 图标亮，错误图标灭。
- A1 使用灯环中的连接指示位置提示连接异常，其余灯光按配置呈现。空气质量灯光、分段灯带、颜色与量程可在灯光设置中调整。

## 按键与恢复

按键动作在松手后识别，恢复操作不会在仍按住时执行。TC1 主按键及 A1 Wi-Fi 键保留恢复手势：按住 5 秒至不足 10 秒后松手重置网络；按住至少 10 秒后松手恢复出厂设置。操作前确认可重新配网，出厂恢复会清除用户设置。

TC1 和 A1 的按键映射支持 1–30 次连击及 1–4 秒长按。连击间隔结束后才执行动作；长按期间每满一秒给出短促灯光反馈，反馈不改变保存的业务灯光设置。5 秒及以上是保留区间，不可作为自定义长按。A1 有功能键及 Wi-Fi 键，默认功能键单击切换风机；TC1 无默认自定义按键动作。童锁会阻止自定义按键动作。可在按键设置中查看、修改和删除映射，相同的连续映射会折叠显示。

M1 按键及硬件恢复方法请参见刷机说明中的机型对应步骤，不要套用 A1/TC1 的自定义按键设置。

## A1 与 M1 联动

M1 只检测、上报并应答授权的 A1。先在 M1 绑定设置中添加 A1:M1 配对标识，再在 A1 配置 M1 成员与联动规则。检查双方网络、MQTT 配置及绑定状态，确认平均读数有效后启用联动。联动开关、阈值、风速策略、防抖与最短切换间隔在 A1 设置；M1 不主动控制净化器。

## 定时、夜间和时间

定时任务使用设备时区。设置 NTP 和时区后确认时间已同步，再启用按周或日期执行的任务。夜间时段结束时间早于开始时间表示跨午夜。不同设备的夜间限制项以界面为准。

## 固件更新

正式构建提供国内外更新来源，在固件设置中选择来源后检查。界面区分发现新版本、已经最新和网络失败；可切换来源重试。确认型号、版本和发布说明后手动点击下载并安装。设备不会因为检查更新而自动安装。

内置来源由构建宏 PHICOMM_OTA_CN_BASE_URL、PHICOMM_OTA_GLOBAL_BASE_URL 写入。未提供来源的自定义构建不显示内置检查入口，但仍保留手动 URL 和本地文件升级。

签名 OTA 使用 .ota.bin.signed；.ota.bin.raw 是原始镜像，仅用于明确选择的无签名救援流程；.all.bin 用于有线刷机，不要当作 OTA 上传。境内镜像为 http://phicomm.fjrcn.cn，境外源为 http://phicomm.fjrcn.com。下载后核对 SHA256SUMS。升级过程中保持供电并等待校验、写入与重启完成。首次从原厂安装按刷机说明执行。

## 管理平台

管理平台支持账号登录、设备列表、MQTT 连接、Legacy 与 TMCP 设备管理。设备控制界面沿用本地 WebUI 的风格。第三方 MQTT 模式与平台账号模式的设备列表、连接凭据相互独立。在线演示全部使用模拟数据，不连接真实设备；刷新可重置。

## 发布与历史归档

Pages 提供最新版及历史版本归档，每个版本保留对应型号的固件、发布说明及校验文件。旧版可能不支持签名 OTA，安装前先阅读该版本说明。发布说明在本 Wiki 的 Release-Log 页面维护；普通使用说明保持通用，不写具体开发版本记录。
