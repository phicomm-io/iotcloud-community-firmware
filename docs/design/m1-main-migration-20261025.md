## 实现边界

Wi-Fi 保留现有配置布局；A1 v10 只在 v9 结构尾部追加滤芯数据，M1 的原厂两档阈值帧与开源 0x70 扩展独立。MCU 二进制响应使用请求拥有的缓冲区；CO₂ 和健康状态进入统一快照，HTTP/MQTT 图编码与直接编码一致。原缓存读数字段继续采用 main 的展示语义。

前端公开锁文件在其 CI 生成 Release 后更新，固件构建固定到已发布资源。原始开发候选版本字符串包含 dirty，不能唯一确定内容；正式包以 tag、提交和镜像 SHA-256 为准。

A1 风量是风速映射估算，不是反馈实测。MCU 升级保留原厂 Bootloader；独立 MCU 发布仍为开发预览版。电气时钟波形、冷上电与长时间稳定性未验收。
