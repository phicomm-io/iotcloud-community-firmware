# A1 滤芯模型与 M1 闹钟迁入 main

## A1 滤芯

同时保留运行时间、加权耗损和估算累计风量。原厂模型使用总容量 12000000，按当前风速换算风量代理值，再按有效 PM2.5/甲醛数据与空气质量阈值的比值，选择权重 15、75、150。社区风速 1–100 映射到原厂 80–390 风量代理；这是估算，未用风量计校准，不等于反馈脉冲测得风量。

`filter.get` 和完整状态的 `filter` 对象新增 `model`、`weighted_usage`、`weighted_capacity`、`weighted_remaining_percent`、`time_remaining_percent`、`air_volume_m3_estimate`。`remaining_percent` 和 `replacement_due` 采用所选模型。`filter.model.set` 参数为 `{"weighted":true}` 或 `false`，切换后持久化，两套计数继续累计。`filter.reset` 同时清零时间、加权耗损和累计风量，保留当前模型；`filter.set` 的寿命小时数作用于时间模型。

网页首页滤芯卡展示两种剩余量、累计风量和模型选择；旧固件缺字段时保留原卡片。保存模型不丢失正在编辑的寿命小时数，写入失败保留原生效值和草稿。OTA、重启及 Wi-Fi 试连期间拒绝修改。

配置版本升为 v10，仅在 v9 的新风字段之后追加 24 字节。迁移保留原网络、按键、CO₂、Bemfa、新风和滤芯使用时间，默认继续使用时间模型。将已有时间寿命比例作为加权初值，累计风量从迁移后开始，避免伪造历史风量。恢复出厂设置默认使用加权模型。计数按原有检查点保存，正常关机/重启预留时保存；突然掉电仍可能损失上次检查点之后的累计值。

## M1 闹钟

在现有自动任务中追加动作 ID 14 `wake_alarm.start`，不改变原有任务结构或动作 ID。支持 `once` 指定 Unix 时间及 `weekly` 周一到周日位掩码；`duration_seconds` 为 1–180 整数，网页默认 60。时钟有效后本地执行，关闭浏览器不影响闹钟。保留任务先持久化再执行、重启不补响、时间回拨不重复执行、禁用/删除及 busy 处理。

网页按能力显示“设置 → 定时与闹钟”，首页提供 3 秒试听、状态与停止按钮；旧固件不显示新控件。时间输入按设备时区转换，仅应用一次偏移，支持 UTC、正负时区，不受浏览器时区影响。

已有 UART 后端每两秒发一个约 300ms 蜂鸣器脉冲；手动停止、屏幕开关事件、OTA、重启、Wi-Fi 试连或超时结束响铃。网页停止入口在 OTA 状态下保持可操作。实际声音模式仍由主控和蜂鸣器硬件决定。轮询返回带代际检查，避免旧读请求覆盖新的启动/停止状态。
