# S30-V1B 原厂免拆 OTA 实测（2026-10-30）

**已在一台 S30-V1B 上完成原厂 `2M.1220` → 社区固件的网络 OTA。** 原厂应用接收正常 AndLink 文件命令，下载完整 RBL，由原厂 bootloader 安装并启动社区应用。随后完成社区配网、浏览器验证和第二次社区网络 OTA。完整回读证明原厂启动区及工厂 MAC/RF 分区未变化。

这里的“免拆”对应从已联网原厂应用开始的升级路径。为恢复明确的测试基线，测试前通过已接好的串口还原了本机原厂备份；串口也用于初始入网诊断、观察日志和最终只读回读。两次验收 OTA 均没有使用串口 `http_ota` 命令、直接写下载区或调试器调用。未单独验收全新原厂设备从未配网开始的完整配网流程。

## 实际采用的固件布局

这是集成工作树中的显式实验选项 `BL2028N/build.py --stock-layout`，没有改变默认上游 bootloader 布局，也没有合入 `main` 或发布。

| 区域 | 物理地址 |
| --- | --- |
| 原厂启动区与间隙 | `0x000000–0x011000`，保留，不随 OTA 下发 |
| 应用 | `0x011000–0x132000`，原厂 CRC 存储与尾块约定 |
| 下载区 | `0x132000–0x1E0000`，696 KiB |
| 工厂 MAC/RF | `0x1E0000–0x1E1000`，原样保留 |
| 原厂 NET info | `0x1E1000–0x1E2000`，社区不作为配置使用 |
| 社区 CFG | `0x1E2000–0x1E3000` |
| 社区 EasyFlash | `0x1E5000–0x1ED000` |
| 社区 LittleFS | `0x1F0000–0x1F8000` |
| 原厂 EasyFlash | `0x1FE000–0x200000`，社区不在这里初始化 |

同时修改了下载地址、长度限制、LittleFS/CFG 地址及构建校验；没有仅移动 OTA 起点。实验模式仅产生纯应用、RBL 和 UG，不生成含上游 bootloader 的 QIO/UA。首次原厂安装允许重新配网，不实现旧社区布局的配置搬迁。

## 原厂网络路径的关键条件

1. 已联网原厂应用可通过正常 CoAP 配置入口设置测试 CGW。此次不需要修改 OpenWrt DNS；临时 Wi-Fi 接口仅用于社区首次配网，完成后已删除。
2. 此原厂版本的 CGW 地址要求 `https://`；测试 HTTPS 服务器必须保持连接，以接收后续 boot/dmReport 请求。测试证书被此版本接受，不代表其它版本相同。
3. 测试 MQTT 需使用 `ssl://`。普通 TCP 分支在本机出现连接准备返回值不一致、反复连接且不发送 MQTT CONNECT；TLS 分支完成了连接、订阅及命令接收。账号和 URL 均保持短小，未利用已定位的 URL 解析溢出。
4. 原厂下行主题按其 MQTT client ID 路由，不能直接假定等于工厂 MAC。正常文件命令包含 `function=file`、`fileMode` 和 `fileUrl`；RBL 由独立 HTTP 服务提供。
5. 升级结果由设备下载日志、启动器安装日志、社区实际服务和完整 Flash 回读共同确认，不能仅看 broker PUBACK。此次没有单独取得设备端文件命令的 MQTT 应用回执。
