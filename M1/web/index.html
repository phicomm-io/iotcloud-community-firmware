Wi-Fi 配网MQTT / HA设备绑定与联动固件升级诊断

Wi-Fi 配网

保存后若热点断开，请切回家庭 Wi-Fi，在路由器中查找设备 IP。连接失败会重新开启配网热点。

MQTT / Home Assistant

legacy 需在平台手动绑定；account 上线后自动加入云端列表。切换账户或模式会尝试清理旧 HA 实体。失败时需在旧 Broker 手动清理。

HA 配置 MQTT 集成后，设备会自动创建四项传感器和亮度控制。

设备设置

填写域名或 IPv4 地址，不含协议和端口。失败后自动尝试阿里、腾讯、国内及全球 NTP 池；每小时校时，失败后 60 秒重试。保存新地址后立即尝试校时。

网页管理密码

密码留空将关闭网页认证；启用后浏览器会要求重新登录。

固件升级

选择本项目的 M1 OTA 包。校验成功后设备自动重启，保留 Wi-Fi、MQTT 和亮度配置。

设备诊断



绑定与联动
先在任一端添加对方 MAC，两台设备使用同一个 MQTT Broker。握手成功后才启用联动。可填写局域网 IP；留空时通过 MQTT 地址公告查找。关闭恢复检查后，可手动探测；强制 MQTT 会停用局域网传输。
